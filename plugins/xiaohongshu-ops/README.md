# Xiaohongshu Operations

Native DSH bundle migrated from `xiaohongshu-ops` 0.4.21. Install its .tgz through iPolloWork Market or the native DSH Plugin Manager. Choose a registered workspace before opening the workbench. Credentials use the native Host credential store; existing local business data is retained. Disable/uninstall releases tools, Skills, routes and child services while retaining data.

In iPolloWork Desktop with account login support, enter the display name and Xiaohongshu ID from the Creator Service Platform, then choose Save and scan. The workbench verifies the account after sign-in. Content settings can be edited later.

Build with `npm run build`. Run `npm run check` and `npm run pack:check` before packaging. See the repository migration inventory for capability-specific verification and limitations.
