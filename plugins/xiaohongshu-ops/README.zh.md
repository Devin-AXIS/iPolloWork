# 小红书运营台

从多引擎分支 `xiaohongshu-ops` 0.4.21 移植的 DSH 原生插件。通过 iPolloWork 市场或原生插件管理器安装 .tgz，选择已有工作区后打开工作台。凭据由原生 Host 凭据提供方保存，保留旧版本地业务数据。停用或卸载释放工具、Skill、路由和子服务，保留用户文件。

在支持账号登录的 iPolloWork 桌面版中，填写创作服务平台昵称及小红书号，点击「保存并扫码」。工作台在扫码后核对登录的账号；账号定位等内容设置可以稍后编辑。

运行 `npm run build`、`npm run check`、`npm run pack:check`。各能力的验收与限制见仓库迁移清单。
