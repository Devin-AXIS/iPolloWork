# iPolloWork 项目看板

[English](README.md) | 中文

安装 iPolloWork DSH 套件后，打开项目中的一个对话，再点击对话顶部的「项目看板」。点击卡片打开任务详情侧栏。可以在项目顶部或直接在状态列新增任务，也可以按名称、说明或负责人搜索任务，或从卡片直接修改状态。窄屏使用状态按钮切换列。任务详情里可搜索并选择成员、AI 智能体和前置任务。支持设置名称、说明、优先级、进度、开始时间、截止时间和前置任务。看板显示未完成任务的截止倒计时。看板、列表、月历和时间线共用同一批任务。已有对话可以在卡片详情中编辑成任务，并继续从详情打开原对话。

## 组织项目

本地工作区关联 iPolloWork 组织项目后，通过 iPolloWork 套件桥接登录账号。看板显示组织名称，通过套件账号服务读取对此项目有访问权限的实际组织成员。负责人和参与人可按姓名、账号邮箱搜索。组织管理员可从「邀请成员」打开套件的项目邀请表单并生成绑定邮箱的链接。对方用受邀账号接受后才进入可选名单。接收人在自己的客户端「任务通知」中看到未读角标，可以打开通知查看详情，并在仍为负责人或参与人时更新进度。有未完成前置任务的卡片必须留在「待处理」。全部前置任务完成后，负责人和参与人会再次收到「可以开始」通知。

在同一份协作名单中通过「参与人」和「参与 AI」添加成员。选人时直接显示姓名和账号邮箱，下方标记「同属成员」。点击成员旁的「设为主负责人」即可切换，原主负责人仍作为参与人。选好成员后，点击「允许所选成员查看当前对话」，可把打开看板的这条对话以只读方式授权给所选成员。授权后可以复制链接，名单会标记已有当前账号授权的成员。保存成员指派后会发送任务通知。

启用套件的[通知中心](../notification-center/README.zh.md)后，看板通知会出现在头像旁的统一入口。选择通知会打开原任务详情，并在组织收件箱确认已读。

个人项目任务保存在 DSH 配置中，可以独立于账号和套件使用。安装套件后，可通过「设置项目归属」把本地工作区关联到组织。组织项目使用共享任务存储，已有个人任务仍存放在本机配置中。组织任务和通知需要更新后的套件 Host 桥接以及账号服务迁移 015。本版本的云端运行时项目凭据暂未开放组织看板权限。

## AI 和自动化

在 DSH 配置中开启官方「Codex 子智能体」或「Claude Code 子智能体」后，提供方和工具加载成功就会出现在「参与 AI」中。两者都可设为主负责人或参与者。点击「交给 AI」会使用所选工具在项目工作目录里委派任务。登录状态和运行错误由各自的原生工具处理。

负责人可选人或 AI，参与人也可以混合选择。独立插件可以选「当前对话 AI」。要加入专员，先在 iPolloWork 套件的「智能体」中创建并启用，看板会读取当前 DSH 配置中可用的专员。组织看板保存专员引用和指派账号。运行需要该账号及本机配置中可用的专员。

将 AI 设为主负责人，给「待处理」任务设置未来的开始时间并保存，即可创建一次 DSH 原生定时任务。时间到了，DSH 会在关联对话中启动任务；没有关联对话时，使用保存任务的项目对话。改期会替换原定时，清除开始时间或 AI 主负责人会取消定时。AI 只作为参与者时不会安排定时。运行需要 DSH Host 和所选 AI 可用。触发时会再次检查任务状态和前置任务，前置未完成则跳过这次启动。

任务可以开始时，也可点击「交给 AI」手动执行。自定义重复执行可用「复制自动化指令」，在项目对话里确认频率。项目对话使用所选工具执行并回传结果，由人负责的任务仍由负责人验收。交互和定时运行都可通过 `ipollo_project_tasks` 读取及更新本项目任务。前置任务全部完成时，组织项目的接收人还会收到账号收件箱通知。

## 构建与验证

先在仓库根目录运行 `npm run setup:build` 准备固定版本的 DSH 源码及类型声明，然后在本目录运行：

```sh
npm ci --workspaces=false
npm run check
npm run pack:check
npm pack
```

通过 DSH 插件管理器添加生成的归档。源码开发可以用官方启动器的 `plugin add link:/absolute/path/to/plugins/collaboration-board` 安装已构建的目录。套件构建会将同一份源码打包为原生子插件。独立构建用于开发和迁移验证。

更换 DSH 固定版本时，在临时配置中验证原生对话标签、聊天草稿恢复、任务编辑与持久化。使用两个账号检查组织指派、未读通知、前置任务解锁和循环依赖拒绝。选择已保存的专员作为负责人或参与人，并在项目会话中验证原生委派，以及宽屏和窄屏下两种主题的四个视图。
