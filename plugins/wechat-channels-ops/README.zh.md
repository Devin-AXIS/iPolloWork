# 视频号运营台

从多引擎分支 `wechat-channels-ops` 0.1.16 移植的 DSH 原生插件。通过 iPolloWork 市场或原生插件管理器安装 .tgz，选择已有工作区后打开工作台。凭据由原生 Host 凭据提供方保存，保留旧版本地业务数据。停用或卸载释放工具、Skill、路由和子服务，保留用户文件。

在支持账号登录的 iPolloWork 桌面版中，点击「扫码添加账号」并用微信扫描官方二维码。工作台从视频号助手核对账号，已有账号用「继续登录」或「检查登录」可复用原会话。如果本机代理导致页面加载缓慢，且登录窗口提供「直连重试」，可在同一账号会话内直连微信登录页及其资源。

运行 `npm run build`、`npm run check`、`npm run pack:check`。各能力的验收与限制见仓库迁移清单。
