# Design

在工作区创建和编辑演示文稿、网页和 HTML 文档。编辑器提供主题、撤销、属性检查和 PowerPoint 导出。你可以从右侧面板或左侧导航打开 Design，在「插件 → 已安装 → Design」中分别设置两个入口。

## 编辑工作区文件

- 通过 `design_open` 打开现有 HTML，或创建、继续设计项目。已启用 Design 时，会话中的 HTML 文件链接可在原生编辑器中打开。交付卡片上的「新建」会创建一份独立的空白 HTML。
- 对已有演示文稿，`ipollowork-design` 技能和 `design_edit_text` 工具支持按版本替换文字，保留模板页数、版式、字体、图片和交互。需要调整结构时也可以编辑 HTML。插件可按幻灯片结构识别演示文稿，普通网页照常保留原有交互。
- 文档支持浏览和文本两种模式。文本模式可编辑正文标题、段落、列表和表格单元格，同时保留源 HTML 的标签、链接、样式和脚本。导航、页脚和装饰性文案不进入正文编辑。

## 预览、批注和历史版本

- 编辑和批注分别有独立的工具栏入口。批注支持框选、画笔、图片叠加、撤销与重做。同一预览中关闭工具栏后仍可继续批注，切换文件或预览版本时重新开始。批注不会写入源 HTML。
- 可以把选中的元素或带批注的截图连同文字指令发送给当前会话。发送失败时保留指令和截图。
- 同一文件的历史版本可独立预览。继续编辑历史版本前会先保留较新的内容。主题修改使用版本校验，保存失败时可重试。浏览模板不会安装模板文件。
- 再次发布同一个设计文件会更新现有公开链接。新版本完整上传后才会替换当前页面，上传失败时原页面仍可访问。

停用插件后，原来的项目文件仍保存在工作区。安装 Design 不会自动下载浏览器。视频生成和渲染请使用 Video。
