# Video

在工作区使用 HyperFrames 制作视频。可以在时间轴中安排画面、音频和字幕，调整主题，预览并导出成片。右侧面板和左侧导航的入口可在「插件 → 已安装 → Video」中分别设置。

## 项目和时间轴

- 通过 `video_open` 创建或继续当前会话的视频项目，也可以打开工作区里已有的视频文件夹或 `index.html`。绑定按会话保存，文件无需移动。会话中的视频 HTML 链接可重新打开编辑器。
- 在时间轴的编辑菜单中选择「复制」，或使用 Ctrl+D／Cmd+D。复制会为新元素分配独立标识，保留已保存的时间安排、受支持的内联样式和 GSAP 动画，也支持撤销。
- `ipollowork-video` 技能可用于原创制作、模板编辑和参考视频分析。`ipollowork_video_reference` 可对当前工作区的本地项目截取参考帧，输出保存在项目的渲染目录。
- 可以把选中的元素作为可移除的标签带入当前会话。主题修改使用版本校验，保存失败的草稿可重试，未完成的生成任务可以继续。

## 导出和服务要求

- 导出使用已配置或系统已有的 FFmpeg 和 FFprobe。受支持的桌面环境缺少工具时，打开视频项目会尝试下载安装，之后可复用本地缓存。首次下载需要网络。
- HeyGen 使用 API 密钥连接。百炼配音默认使用 Qwen3-TTS-Flash，项目可保留生成的 MP3。
- 视频工作台沿用桌面布局。停用插件后，项目文件仍保存在工作区。
