# iPollo Decision Intelligence

Use a workspace conversation to investigate a decision or analyze a PowerPoint file. The plugin organizes industry relationships, driving factors, key metrics, and evidence into a map. Open individual nodes to review their sources.

## Use the plugin

1. Ask for a decision map in a workspace conversation. You can attach a PowerPoint file as reference material.
2. In the right sidebar, select **Add tab → Decision Intelligence**. The map is saved in the current workspace and supports switching between revisions.
3. Download the map as a standalone web page, or confirm publishing to create a guest link.

An investigation needs a configured model and a writable workspace. Saving through App Data requires an iPolloWork account. Sharing online requires publishing access.
