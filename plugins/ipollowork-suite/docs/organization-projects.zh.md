# 组织项目与本地工作区

组织项目保存团队共享的产物、待接纳改动和已接纳记忆。本地工作区保存当前电脑上的会话和文件。关联工作区后，每一轮 AI 工作都会重新检查项目权限并读取已接纳的记忆；普通聊天、本地文件修改不会自动上传为组织项目内容。

## 正常显示与使用

1. 打开组织空间的项目，在页面下方展开“我的本地工作区”，选择本地工作区并点击“使用此工作区”。
2. 直接分享完成的产物：在项目“文件”中选择文件，再点击“上传”。上传完成后，有权限的其他成员可以查看和下载。
3. 需要维护者审阅的文件或知识：点击“提交”，选择“提交文件”或“提炼知识”。提交先出现在“改动”，状态为“待接纳”；此时已接纳文件和项目记忆保持原版本。
4. 维护者在“改动”中审阅并接纳。项目文件或记忆更新，概览中的贡献记录和版本随之更新。关联工作区之后的新一轮 AI 工作会读取新版记忆。
5. 分享整段对话：在会话页面分享给指定组织成员，接收者到组织空间的“共享会话”复制打开。组织项目不会自动收录所有本地聊天。

页面每 12 秒刷新可见项目，回到窗口或点击“刷新”也会更新概览、文件、记忆和待接纳改动。上传需要当前项目允许输出上传，操作权限也受项目角色限制。

## 成员权限

成员权限弹窗只保留逐成员的查看、参与、维护授权。全员范围、部门授权入口及生成邀请码已移除。已有项目打开弹窗时不会改变授权；明确保存时，将当前旧范围产生的有效角色转为当前成员的个人授权。组织管理员、项目所有者等服务端固有权限仍由服务端执行。

## 文件选择

项目上传、项目提交、成员 CSV、组织 Logo、共享 Skill、HTML 模板采用同一选择控件。支持点击选择、拖放、显示文件名和大小、移除、替换及就地错误反馈。格式与大小限制沿用各表单规则。选择文件并不表示上传，需完成相应表单的上传或提交。其他可见 Host 原生文件输入具有主题兜底样式；独立 iframe 插件的样式由该插件管理。
