# iPolloWork 套件

为 DSH 添加 iPolloWork 品牌外观、渐变输入框、自有插件市场和账户入口。原有会话、模型和功能插件继续由 DSH 管理。

在侧边栏打开“智能体”，只需填写名称和工作要求即可创建助手，也可上传头像。模型默认跟随当前选择，或为单个助手指定已有模型。技能和服务按需展开，从 DSH 已有配置中选择。同一个智能体可用于多个项目，各项目的会话和记忆分别保存。主助手可通过 DSH 原生子智能体机制调用多个智能体协作。

会话列表顶部固定显示“总助手”入口，点击继续聊天，旁边的加号可新建总助手会话，模式始终为总助手。“智能体”页面只管理固定专家。总助手可以直接完成任务，也可以调用固定专家或按需创建临时助手。企业微信、钉钉、飞书等连接在扫码或自动绑定后，新会话都使用各自独立的总助手，不需要为专家分别扫码。总助手收齐内部协作结果后，在原聊天返回答复。网页入口与各个 IM 聊天分别保存会话；已有聊天发送 `/new` 后启用总助手，不删除旧记录。

在“插件”页面打开“iPolloWork 市场”，可以搜索我们收录的 DSH 插件、查看详情，并通过 DSH 的安装界面管理它们。DSH 已提供的插件直接打开原生详情。

左下角的“iPolloWork 账户”可连接 iPollo 账户并读取可用积分。不登录也可以使用本地功能和公开市场。断开账户只清除本机保存的这份登录凭证，不删除账户或会话。

此版本的企业目录尚未连接。完整的企业管理员权限和租户隔离仍需后续接入。请勿将套件本身当作隔离不可信插件的安全机制。

专用桌面发行版保留原来的欢迎、额度、用途和流程引导页，使用 iPolloWork 品牌和账户。登录页支持邮箱密码登录，也可填写昵称、邮箱和至少 10 位密码注册。套件随安装包提供并固定启用。

账号模型渠道在 iPolloWork 下显示后台名称。未配置个人提供方 Key 时，登录自动选择可用的账号渠道；已选择的账号渠道保持不变。用户可通过原生“模型”设置添加、选择个人 Key 提供方。账号推理使用私有本地网关令牌；积分不足显示为账号额度问题，不显示为 Key 错误。

内置 IM 使用 Cordis 的公开根上下文标识。Design 和 Video 使用已验证的原生源码构建，包括自动识别演示文稿及原生 Video 入口。
