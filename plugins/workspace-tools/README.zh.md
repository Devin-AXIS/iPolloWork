# 工作区工具

iPolloWork 市场分别提供 Markdown 编辑、Excel 编辑、对话导出、任务模板、参考资料整理和旧版工作区导入。切换到独立插件前，请停用旧工作区工具合集。任务模板和旧版工作区导入继续使用原有模板数据，之前保存及导入的模板可继续使用。

通过 iPolloWork 的插件管理器安装并启用归档。在本地工作区对话的文件预览工具栏点击「编辑」，可以编辑 Markdown 与 XLSX 文件。Markdown 支持格式命令、预览和快捷键保存。XLSX 支持切换工作表并修改普通单元格的值，公式区域和受保护的单元格保留原样。文件在外部变更后，编辑器保留草稿并报告冲突。

左侧会话菜单提供「导出对话 Markdown」和「保存为任务模板」。对话右侧的「工作区工具」可管理模板、整理参考资料，以及预览和导入旧工作区导出的命令和 Skills。模板用于准备新对话草稿。参考资料在本地解析，原文件、提取证据、素材和索引保存在项目的 `references/` 目录。扫描 PDF 需要先做 OCR。

安装旧版配置时，命令变为可编辑的任务模板，Skill 写入当前项目的 `.agents/skills/`。同名 Skill 原文件保留。

运行 `npm ci`、`npm run check` 和 `npm run pack:check` 验证，运行 `npm pack` 生成安装归档。
