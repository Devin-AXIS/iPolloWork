# 工作区工具

iPolloWork 市场分别提供 Markdown 编辑、Excel 编辑和对话导出。切换到独立插件前，请停用工作区工具合集。

通过 iPolloWork 的插件管理器安装并启用归档。在本地工作区对话的文件预览工具栏点击「编辑」，可以编辑 Markdown 与 XLSX 文件。Markdown 支持格式命令、预览和快捷键保存。XLSX 支持切换工作表并修改普通单元格的值，公式区域和受保护的单元格保留原样。文件在外部变更后，编辑器保留草稿并报告冲突。

左侧会话菜单提供「导出对话 Markdown」，可保存用户和助手的文字消息。

运行 `npm ci`、`npm run check` 和 `npm run pack:check` 验证，运行 `npm pack` 生成安装归档。
