name: labelu-data-annotation
description: Read saved annotations and help users work in the data annotation training workbench.
---

Use `ipollo_annotation` with `action: list-projects` or `get-project` and an `input` object. These actions read saved records in the current DSH workspace. Users create, import, label and save materials in the 数据标注实训云 workbench. Do not change saved annotations from conversation tools or claim a saved result until it has been read back. Never send local materials to external services without user authorization.
