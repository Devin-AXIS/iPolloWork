# 项目文件

项目文件是 iPolloWork 和 DeepSeek Harness 的原生右侧标签。打开项目对话，展开右侧边栏，选择「项目文件」。

- 首页只有**输入**和**输出**。用顶部「本次对话 / 整个项目」切换查找范围。项目视图优先显示本次对话的文件，重复的文件只显示一次。文件统一使用紧凑条目，末尾的「⋯」打开文件操作。有交付标题时显示标题和原文件名。网页点击预览，图片在图标位置显示小缩略图。网格或列表排列作用于整个面板。
- **输入**汇总项目各个对话发送的附件和记录中的项目内 `@文件` 引用。附件可以下载原件，也可以复制一份到项目目录。引用文件用原生预览打开。
- **输出**优先展示明确交付的文件，之后是有记录的成功写入和工作区变更。交付的目录内有 `index.html` 或 `index.htm` 时，可从首页直接打开原生网页预览。「项目目录」显示实际文件夹，也包含对话没有记录的文件。
- 在项目目录中，单击选择，双击或按回车打开。右键或用 Cmd/Ctrl+C、X、V 复制、剪切和粘贴。拖到文件夹或目录路径可移动，按住 Option/Alt 拖放可复制。F2 改名，移到废纸篓的文件可在「最近删除」里恢复。
- 文件变更限定在当前 DSH Host 的已校验本地工作区内。复制和剪切使用插件内当前项目的文件剪贴板。

iPolloWork 套件内的子插件 ID 为 `ipollo-project-files`。也可以在原生插件管理器独立安装 `@ipollo/dsh-project-files` 归档，同一 profile 任选一种方式。

完成仓库的固定 DSH 准备后，在此目录执行 `npm ci`、`npm run check` 和 `npm run pack:check`。更新工作 profile 前，在临时配置中安装和验证归档。
