# Douyin Operations

Native DSH bundle migrated from `douyin-ops` 0.2.22. Install its .tgz through iPolloWork Market or the native DSH Plugin Manager. Choose a registered workspace before opening the workbench. Credentials use the native Host credential store; existing local business data is retained. Disable/uninstall releases tools, Skills, routes and child services while retaining data.

In iPolloWork Desktop with account login support, choose Add by QR code. After scanning, the workbench checks the Douyin ID on the signed-in profile page and refreshes the account status. Use Check login to verify an existing account.

Build with `npm run build`. Run `npm run check` and `npm run pack:check` before packaging. See the repository migration inventory for capability-specific verification and limitations.
