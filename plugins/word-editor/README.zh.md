# Word 编辑

在 iPolloWork 插件管理器安装并启用归档。在本地项目对话中打开对话生成的 DOCX，或从「项目文件」打开 DOCX，右侧会直接进入 Word 编辑。需要时可以用文档工具栏切回系统预览。

支持分页编辑、文字与段落格式、表格、图片、链接、列表、标题导航、查找、撤销重做与页面设置。输入停顿后自动保存到当前文档，也可用 Ctrl/Cmd+S 手动保存。「下载副本」可导出正在编辑的文档。写入会核对磁盘版本，文件在外部变更时可下载当前草稿。

编辑器随插件交付，在本地客户端运行。缺少字体时页面换行和分页可能变化。编辑适用于本地工作区的 DOCX 文件。旧格式 DOC、密码保护或签名文档、修订协作等高级审阅功能暂不支持。

`vendor/eigenpal` 保留固定版本的 Apache 2.0 源码，包括核心、中文等语言资源和 React 适配器。使用 Node 24 和 Bun，依次运行 `npm ci`、`npm run build:source`、`npm run check` 和 `npm run pack:check`，再用 `npm pack` 构建安装归档。浏览器编辑器从随仓库保存的源码构建。
