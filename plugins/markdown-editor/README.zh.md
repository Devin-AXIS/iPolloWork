# Markdown 编辑

从对话或项目文件树打开本地 `.md` 或 `.markdown`，在右侧工作区点击「编辑」。标题、表格、代码块和图片会直接渲染。输入 `/` 可插入内容块，选中文字会显示格式工具栏。编辑会自动写回原文件，也可点击「保存」或按 Ctrl/Cmd+S 立即保存。

实时预览和编辑命令移植自 iPolloWork 多引擎分支的 `05f917145cd320a93e514dbd01178133891bc4c6`。

安装 `plugins/workspace-tools` 的构建依赖后，在仓库根目录运行 `npm run package:workspace-market` 构建并打包。
