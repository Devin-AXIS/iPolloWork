# Markdown Editor

Open a local `.md` or `.markdown` file from a conversation or the file tree, then choose Edit in the right workspace. Markdown formatting, tables, code blocks, and images render inline. Type `/` to insert a block, or select text to bring up formatting controls. Changes autosave to the original file. The Save button and Ctrl/Cmd+S save immediately.

The live preview and editing commands are adapted from iPolloWork's multi-engine branch at `05f917145cd320a93e514dbd01178133891bc4c6`.

Build and package from the repository with `npm run package:workspace-market` after preparing the dependencies in `plugins/workspace-tools`.
