# iPolloWork Video Studio

This is the single video authoring entry. Built-in Studio, timeline, media and export services exist independently of these Skills.

1. Read the active task contract, exact project entry, confirmed brief/template and tokens. Preserve current user edits; own only this session's `video/<session-id>/` project. Never create another project/server or restart/install app services. Immediately before a complete write re-read and merge current disk content.
2. Load only applicable sections of [references/video.md](references/video.md), once for unchanged requirements. Creation/full regeneration must read Plan content and storyboard, Native editable script, Recipes, components and sequence, and Composition and timing before drafting; those sections are required creation input. The runtime supplies paths, port, selected/default voice, delivery requirements, review flag and render ownership; reference guidance never overrides them.
3. Create from content and audience events, then query the executable recipe catalog once for suitable intent/inputs/capacity. Install and mount fitting recipes; when none fits, record the concrete mismatch and author editable custom work without forcing a match, proportion or shot count. Save native `STORYBOARD.md` before media/assembly: leading frontmatter, `## Frame N` and separate `- key: value` fields, never a Markdown pipe table. Continue by default; explicit script-review or script-only work stops at the saved script until approved. Targeted edits preserve unrelated work.
4. Preserve project media, the authoritative seekable timeline, `design-tokens.css`/`--ipw-*` theme inheritance, static `data-composition-variables`, stable IDs and editable nodes/hooks in recipes and custom scenes. Later theme/token changes retain editable content and timing. For speech use `ipollowork-video-voiceover` only when enabled/authorized or explicitly requested. Required media/captions/audio persist until implemented or user-cancelled; unavailable requirements mean an unfinished scope, never fabricated completion.
5. Save the complete entry and follow the client-owned validation/export continuation. Publish only when explicitly authorized, reusing its account/draft/job; export alone does not authorize publishing.
