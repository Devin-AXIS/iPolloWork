## 小红书点击打开导致软件退出

已在真实桌面复现，browser 进程退出码为 0x80000003。转储符号定位到 Chromium 的 AddOriginAgentClusterStateForBrowsingInstance_Cpp。小红书 HTTP 页面返回 Origin-Agent-Cluster: ?1，桌面原先把它转发到 dsh-app:// 专用协议，触发底层检查。

修复：桌面转发过滤该 HTTP 来源响应头，保留 CSP/CORP；HTTP Host 的原响应不变。已在用户实际 Electron 开发版验证首次打开、发帖/评论/数据切换、新增账号弹窗、Escape 关闭，以及离开插件后再次打开；同一桌面进程保持运行。原账号、草稿与素材未被修改。另为子进程显式保留 Electron Node 模式，并修复旧包未成功替换的问题。

代码：integrations/desktop/src/web-document.ts；回归：integrations/desktop/tests/web-document.spec.ts。仅发布插件 tgz 不会替换旧的桌面外壳，其他桌面安装也需要带上这个外壳修复。正在其他对话准备的 DSH 升级候选版需要同步该修改后重新验证。
