# iPollo 1.0 package audit

## Measured comparison

The official DSH 0.2.2-rc.3 macOS arm64 DMG is 276,328,312 bytes (263.5 MiB), read from its production download endpoint. The first corrected iPollo DMG is 551,245,746 bytes (525.7 MiB). The slim audit DMG is 292,836,477 bytes (279.3 MiB), using the same ULMO compression family. The slim audit image is not a signed release artifact.

The official application's dependency payload totals about 404 MiB. iPollo's slim dependency payload totals about 445 MiB; the main additional package is the iPollo suite (27 MiB including its nested dependencies), followed by service/IM dependencies. Both distributions retain Electron (286 MiB) and the primary runtime (299 MiB).

## Cause and correction

Desktop previously added Design and Video to its required package set, installed their dependency trees and carried 104 MiB of the same plugins' installer archives. Their dependency trees included Transformers, ONNX and browser/build tools. Desktop now includes only its suite and the official runtime dependency closure. The staged desktop suite archive removes Design/Video resource dependencies and installer archives. Other suite distribution modes retain their own resource delivery behavior.

The dedicated desktop market lists pinned GitHub tarball URLs without downloading archives while listing. The two published plugin archives match the SHA-256 records in the catalog. DSH performs installation only after the user chooses the plugin. Native dependency scripts retain DSH's build approval behavior.

## Validation

- Desktop package selection and runtime file policy: 35 tests passed.
- Suite check: 151 passed, 11 skipped; package dry-run passed.
- Focused market tests: 10 passed.
- Desktop TypeScript check passed.
- Slim built application: frontend, account and IM routes, package installation/removal, Office skills, PDF/image conversion and spreadsheet recalculation passed.
- Final slim application excludes Design, Video, both resource packages, Transformers, ONNX Node/Web and embedded Studio tarballs.
- Disposable profile: Video downloaded from the published URL; its pinned native dependency scripts were approved only in the test profile, then esbuild, Sharp and ONNX loaded successfully.

The published 526/540 MiB installers remain the previous signed builds. Replacing them requires fresh signed builds and notarization. Linux and Windows ARM remain unsupported by the current desktop packaging target implementation.
