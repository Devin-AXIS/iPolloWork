# iPolloWork 1.0.8

- PPT 模板生成自动带入 Design Skill 和模板清单，新增按版本检查的文字修改工具，保留模板版式、字体、图片和幻灯片结构；HTML 产物可直接进入 Design 编辑。
- 修复 Design 百分比及相对尺寸在属性栏中的解析、元素属性入口、主题重置和 PDF 后台导出；内置 Design 更新至 `1.0.0-beta.37`。
- MCP 设置增加断开、重连和删除入口；修复组织 MCP 协议协商及余额查询影响连接同步的问题。
- 组织空间按“部门、成员、项目”排列前几个标签页，完善项目协作刷新、上传控件、共享资源信息校验和版本标签。
- 完善通知已读与失败重试反馈，以及模型输入限制和组织服务异常的提示。

桌面安装包连接 `cloud.ipollo.net`。Mac 安装包沿用签名、公证流程，Windows 包延续现有未签名分发方式。升级保留已有账号、会话、工作区和配置。

先前已经重新绘制的 HTML 保留原文件；要使用修复后的 PPT 模板生成流程，请重新选择模板创建会话。第三方媒体生成和外部网页发布不属于本次完整验收范围。

Design 的定位、修复与验证范围见 [检查记录](../design-template-fidelity-2026-11-19.md)。
