# iPolloWork 1.0.9

- Repair startup when an installed plugin has hoisted obsolete DSH core dependencies into the desktop profile. Back up mismatched core package entries before using the application's pinned runtime; retain plugin packages, configuration, credentials, workspaces and conversations.
- Keep the failed plugin and its original error visible in the bounded startup dialog, alongside the saved diagnostic report.
- Publish Windows website installers using `ipollowork-win-x64-<version>.exe`. These aliases preserve the original unsigned bytes; automatic updates keep their explicit `-unsigned` payload name.
- Publish fixed direct-download aliases for all four supported platforms, verify their public availability, and include them in the checksum manifest. The website no longer needs a successful GitHub API call to start a supported-platform download.
- Preserve failed Mac applications and their source/hash records. Check the real DMG-installed application with an obsolete local core dependency before uploading the release, in addition to the existing runtime and Office checks.

DSH remains pinned to `0.2.2-rc.3`; no upstream implementation or signing permissions are changed.
