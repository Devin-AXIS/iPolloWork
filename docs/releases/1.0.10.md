# iPolloWork 1.0.10

- Repair existing desktop profiles that omit the required iPolloWork application bundle after an upgrade. Preserve user plugins, workspaces, conversations and credentials; back up the original profile manifest.
- Restore installation-owned product packages and application entry points when obsolete or disabled profile entries would load the base DSH interface. Preserve custom settings outside the distribution's required account, branding and cloud endpoint.
- Distinguish incorrect passwords from rejected sessions, unavailable authentication services, timeouts and throttling in the native sign-in window.
- Require the installed Mac acceptance check to exercise real cloud sign-in, an upgraded legacy profile and a returning signed-in workspace, in addition to signature, Gatekeeper, runtime and Office checks.

DSH remains pinned to `0.2.2-rc.3`. The account service and its database are unchanged.
