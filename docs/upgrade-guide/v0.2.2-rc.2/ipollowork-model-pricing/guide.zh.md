# iPolloWork 模型计费

[English](guide.md) | 中文

## 变更

iPolloWork 独立账号服务不再向用户目录返回缺少 Key、有效价格或已启用模型记录的官方模型。启用未定价模型会被拒绝，明确标记的免费模型仍受支持。已有服务 Key、管理员编辑的价格和数据库记录都会保留。

管理后台按共享 Key 分组连接。百炼的语言、图像、视频、语音合成、语音识别和向量模型使用同一个 Key。同步目录只追加模型，不会自动启用新模型或覆盖管理员的改动。异步图像和音频任务与视频任务一样，在取得最终结果后结算积分。

## 迁移

1. 备份 PostgreSQL 和账号服务认证密钥，再构建并重启 `services/ipollowork`，无需迁移数据库结构。
2. 使用管理员账号打开“服务中心”，统一配置服务商 Key，并核对所属地域的 API 域名。点击“同步全部模型”导入百炼目录。
3. 核对每个已启用模型的输入、输出单价、计费单位、上下文阶梯和价格有效期。只有供应商成本为零时才标记免费，未核定价格的模型保持不可用。
4. 确认已配置模型出现在用户目录，未配置模型不会出现。开放付费流量前检查一次预扣和结算；供应商结果不明确时保留预扣，等待核对。
