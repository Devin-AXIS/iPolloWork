# 客户端交互说明（现状）

> 本文按当前客户端实现整理，面向产品、设计、研发和测试。以 Electron 桌面端为主，同时标出共享 Web 界面的能力差异。内容描述的是现有行为，不代表后续交互方案。最后更新：2026-08-26。

## 1. 产品里的几个核心概念

| 用户看到的概念 | 实际含义 | 主要操作 |
| --- | --- | --- |
| 项目 | 一个独立的工作区，绑定目录、Agent 引擎、模型与权限配置 | 新建、重命名、打开目录、移除、在项目内新建任务 |
| 任务 | 一次可持续进行的 Agent 会话 | 输入要求、追加消息、查看执行过程、重命名、归档、删除 |
| 对话 | 任务中的消息与执行记录 | 发送、排队、停止、查找、导出 |
| 工作台 | 任务右侧的可操作产物区域 | 浏览网页、编辑设计、查看文件、制作视频、使用插件工作区 |
| 扩展 | 安装后可被所有项目使用的能力包 | 浏览、安装、启用、配置；内部可包含 Skills、MCP 和工作区页面 |

客户端的主路径可以概括为：

```text
启动客户端
  └─（按部署要求）登录
      └─ 进入项目
          └─ 新建或打开任务
              ├─ 在对话区描述要求并运行 Agent
              ├─ 在执行中追加排队消息、回答问题或批准权限
              └─ 在右侧工作台查看和编辑 Agent 产物
```

## 2. 整体界面结构

常规任务页由四个区域组成：

1. **左侧边栏**：全局入口、项目与任务列表、账号、设置和通知。
2. **中间主区域**：新任务起始页、对话、项目概览、项目任务板、日程或扩展页。
3. **右侧工作台**：网页、Design、文件、视频、插件工坊和插件提供的工作区页面。
4. **底部终端**：按需展开的项目终端。

左侧边栏和右侧工作台都可以调整宽度。窗口空间不足时，客户端会优先收起边栏或工作台，为中间主区域保留可操作空间。

## 3. 启动与登录

### 3.1 启动

- 客户端启动时显示全屏加载层，等待本地服务、工作区和当前路由准备完成。
- 首次运行如果还没有任务，会自动准备基础资源并创建初始任务；此时显示“正在安装所需资源”状态。
- 如果当前项目使用的 Agent 引擎尚未安装或没有启动，主区域会先显示安装或启动引导，完成后再进入任务。

### 3.2 登录

登录不是所有部署的必经步骤。只有部署配置要求强制登录、且本机没有有效会话时，才会出现全屏登录页。

- “登录”和“注册”会打开系统浏览器。
- 浏览器完成认证后，通过客户端深链自动回到应用。
- 如果浏览器无法自动唤回客户端，用户可以展开手动认证区，粘贴授权码或完整深链。
- 开发或私有部署可以修改组织服务器地址；切换地址后会清除旧登录会话并重新检查。
- 非强制登录环境中，用户也可以从左下角账号入口主动登录。

## 4. 左侧边栏

### 4.1 顶部全局入口

| 入口 | 当前行为 |
| --- | --- |
| 搜索 | 搜索所有项目里的任务标题和消息内容 |
| 新建任务 | 在当前选中的项目中进入空白任务起始页 |
| 模版 | 打开模板市场弹窗，可预览、安装、更新和使用模板 |
| 日程 | 在主区域打开全局日程与任务视图 |
| 扩展 | 在主区域内嵌打开扩展管理页 |
| 插件工坊 | 在右侧工作台打开插件创建与调试界面 |

### 4.2 项目列表

- 点击“项目”标题旁的加号，可在桌面端新建项目。
- 新建项目时填写名称，可选择本地目录，并选择 OpenCode、DeepSeek Harness 或 Codex Harness 引擎。
- **当前实现中，点击项目行只会展开或收起任务列表，不会直接切换当前项目。**
- 项目行悬停后出现两个操作：
  - `+`：直接进入该项目的空白任务起始页。
  - `…`：重命名、打开项目 Builder、在文件管理器中显示、移除项目。
- 远程项目不可在本机文件管理器中显示。
- 远程项目连接异常时，项目下方显示错误卡片，并按状态提供恢复、测试连接和编辑连接信息等操作。

### 4.3 任务列表

- 点击任务会打开该任务；鼠标悬停或键盘聚焦时会预加载内容。
- 派生任务以树形结构显示，父任务右侧箭头控制展开和收起。
- 运行中任务显示旋转状态；等待用户输入、错误等状态使用不同颜色提示。
- 每个项目先显示有限数量的任务，点击“显示更多”继续加载。
- 已归档任务放在独立的“已归档”分组中，默认收起。
- 任务的 `…` 菜单和右键菜单提供相同的管理操作：置顶/取消置顶、重命名、归档/取消归档、删除。
- 删除任务和移除项目都会先弹出确认对话框；重命名使用独立输入对话框。

### 4.4 底部账号与系统入口

- 已登录时显示当前账号或组织；点击后进入“账号”设置。
- 未登录时显示登录入口。
- 齿轮菜单提供“设置”“帮助中心”和中英文切换。
- 通知铃铛打开通知中心；通知可根据内容跳转到相应设置页。

## 5. 新建任务

进入空白任务后，主区域显示任务类型和输入框。用户可以直接输入，也可以先选择一个任务方向。

### 5.1 任务类型

| 类型 | 快捷入口 |
| --- | --- |
| 工作 | 自动操作电脑、文档处理、表格处理、深度研究、操作浏览器 |
| 代码 | 理解代码、开发功能、排查问题 |
| 创作 | 做网站、做 PPT、信息卡片、海报，以及更多创作模板 |
| 视频 | 视频模板；选中后进入视频生成流程 |

- 工作和代码快捷入口会把一段起始要求填入输入框，用户仍可继续修改。
- 创作入口按品类展示模板。已安装模板可以直接使用，未安装模板先执行安装。
- 使用设计或视频模板时，客户端可能先展示 Brief 表单，要求填写主题、受众和补充信息；参考文件上传为可选项。
- 长文档参考会先在本地解析，并根据内容尝试补全 Brief。用户可以选择是否把原文件一并发送给 Agent。

## 6. 对话与输入框

### 6.1 基础输入

- 输入框支持多行文本，`Enter` 提交，`Shift + Enter` 换行。
- 可以通过按钮、拖放或剪贴板添加文件；单个附件上限为 8 MB，图片会先压缩。
- 较长的粘贴内容（至少 3 行或 200 个字符）会折叠成输入框内的文本卡片，避免占满编辑区。
- 输入 `/` 可搜索命令、Skills 和 MCP 命令；输入 `@` 可引用文件、Agent 或插件工作区。
- 点击 `+` 可以添加文件、打开工具选择器，或把任务委派给已连接的外部 Agent。
- 工具选择器按命令、Skills、MCP、扩展分类展示；未配置的能力会引导用户进入相应设置页。
- 输入框底部可以切换模型、推理强度和 Agent 工作模式。任务正在执行时，部分选项会锁定。
- 输入内容按任务保存草稿；在空输入框中按方向键上/下，可以找回此前发出的要求。

### 6.2 发送与运行中交互

空闲状态：

- 点击发送按钮或按 `Enter`，立即开始执行。
- 没有内容和附件时点击发送，会显示“请输入任务内容”的提示。

Agent 运行中：

- 再次提交的消息会进入队列，不会打断当前执行。
- 队列显示在输入框上方，可逐条或批量移除。
- 停止按钮会立即请求终止当前执行。
- 连按两次 `Esc` 也可以停止：第一次出现确认提示，3 秒内再次按下才会执行。
- 如果 Agent 发起问题、待办或权限申请，相应面板会显示在输入框上方；需要用户完成回答或批准后，任务才能继续。

### 6.3 对话区

- 对话按消息顺序显示用户要求、Agent 回复、思考过程和工具执行结果。
- 用户可以回到最新消息或某条消息的起点。
- 支持在当前对话中查找文字。
- 消息级操作包含回退到某条用户消息、从某处派生任务、编辑后重新发送等；是否显示取决于消息类型和引擎能力。
- 标题栏 `…` 菜单可将当前任务保存为提示模板、导出 Markdown、重命名或删除任务。
- 没有连接任何模型提供商时，输入框上方显示提醒；点击后进入 AI 提供商设置。
- 模型不可用、任务加载失败或执行错误时，错误信息在对话区内显示，并提供换模型、重试或关闭提示等恢复入口。

## 7. 项目内的三个视图

非默认项目在主区域标题栏中提供三个视图：

| 视图 | 用途 |
| --- | --- |
| 对话 | 当前任务的消息与 Agent 执行过程 |
| 概览 | 项目说明、引擎与模型状态、运行概况 |
| 任务 | 项目内工作项的看板或列表 |

窄窗口下，这三个入口会收进下拉菜单。打开左侧某个具体任务时，主区域会回到“对话”视图。

## 8. 右侧工作台

标题栏右侧按钮用于打开或收起工作台。首次打开时显示工具启动器；之后会恢复当前任务上次使用的面板。

| 工作台能力 | 当前行为与限制 |
| --- | --- |
| Web | 桌面端内置浏览器；支持多标签、地址栏、前进、后退、刷新和标签右键菜单 |
| Design | 打开设计模板或设计文件，支持预览、编辑、导出和 AI 辅助编辑；远程项目不可用 |
| 文件 | 展示 Agent 在对话中产出的可访问文件；没有产物时不可用 |
| 视频 | 打开视频制作与预览面板；远程项目不可用 |
| 插件工坊 | 创建、检查和调试插件 |
| 插件工作区 | 由已安装插件提供的自定义界面，可把当前界面上下文带入同一任务继续询问 Agent |
| 输出 | 从标题栏单独打开，汇总当前对话检测到的产物 |

- 工作台支持多个标签，用户可以切换和关闭标签；浏览器标签支持拖动排序。
- 面板边缘可拖动调整宽度，也可以放大为主要工作区域。
- 对话里检测到网址或产物路径后，可以直接在对应工作台中打开。
- 内置浏览器只在 Electron 桌面端可用，网页部署不会提供原生浏览器面板。

## 9. 日程、模板与扩展

### 9.1 日程

- 左侧“日程”在主区域打开全局工作视图，可按日期查看和定位工作项。
- 项目标题栏中的“任务”打开当前项目的工作看板。
- 左侧边栏收起后，日程页标题区会显示恢复边栏按钮。

### 9.2 模板

- 左侧“模版”打开浮层市场，不离开当前任务上下文。
- 模板按网站、幻灯片、海报等类型浏览。
- 模板卡片支持预览、安装、更新、使用和卸载；也可导入本地模板包。
- 使用模板后会创建对应类型的任务，而不是直接覆盖当前普通任务。

### 9.3 扩展

- 左侧“扩展”会在主区域内嵌打开扩展设置，并保留主应用边栏。
- 扩展页以“插件 / Skills”分段切换，支持浏览已安装能力和插件包详情。
- 齿轮菜单进入的是完整设置页；其中的“扩展”是同一套数据的完整设置入口。

## 10. 设置

完整设置页分为三组：

### 项目

- **偏好设置**：默认模型、推理强度、上下文压缩等当前项目偏好。
- **权限**：授权 Agent 可访问的文件夹和文件。
- **扩展**：插件包与 Skills；插件还可以在这里贡献自己的设置页面。

### 全局

- **AI 提供商**：连接模型服务、选择和断开提供商。
- **引擎管理**：安装和管理本机 Agent 引擎。
- **授权中心**：配置生成、媒体和存储服务所需的凭证。
- **自定义**：品牌、起始卡片、边栏等应用外壳选项。
- **外观**：主题、语言和窗口标题栏设置。
- **环境变量**：保存在本机、供 Agent、Skills 和 MCP 使用的密钥与变量。
- **更新**：检查、下载并安装客户端更新。
- **恢复**：重置配置和修复本地状态。部分恢复按钮目前仍是占位实现。
- **调试**：仅开发者模式显示，用于查看运行时状态和调试工具。

### 云端

- **账号**：登录状态、个人云端空间和组织相关操作。
- **记忆**：功能开关启用后显示，可查看和删除 Agent 已记住的内容。

“连接”“插件市场”“云端提供商”等页面当前仍有独立路由，但不在常规设置侧边栏中固定展示，通常从账号、组织能力或上下文提示进入。

## 11. 常用快捷键

macOS 使用 `Cmd`，Windows/Linux 使用 `Ctrl`。

| 快捷键 | 行为 |
| --- | --- |
| `Cmd/Ctrl + N` | 在当前项目中新建任务；输入框聚焦时不触发 |
| `Cmd/Ctrl + K` | 打开命令面板，可新建/切换任务、换模型、换工作模式、打开设置或产物 |
| `Cmd/Ctrl + J` | 打开或收起底部终端 |
| `Cmd/Ctrl + F` | 在当前对话中查找 |
| `Cmd/Ctrl + Shift + F` | 搜索所有任务的标题和消息 |
| `Enter` | 空闲时发送；运行中加入队列 |
| `Shift + Enter` | 输入换行 |
| 连按两次 `Esc` | Agent 运行中请求停止 |
| 空输入框 `↑ / ↓` | 浏览历史输入 |
| 浏览器内 `Cmd/Ctrl + L` | 聚焦右侧浏览器地址栏 |
| 右侧多标签时 `Ctrl + Tab` | 切换工作台标签 |
| `Cmd/Ctrl + +/-/0` | 放大、缩小或重置客户端字体显示 |

## 12. 状态与反馈原则

- 耗时操作使用加载动画、按钮禁用或骨架屏，避免重复提交。
- 成功、失败和警告使用右下角 Toast；需要用户立即处理的内容尽量留在当前区域内。
- 删除、移除等破坏性操作需要二次确认。
- 远程项目无法执行的本机操作会隐藏、禁用或给出明确提示。
- 组织策略限制某项设置时，设置页顶部显示策略说明；受限操作不会静默失败。
- 当前项目、任务和设置页均以 URL 中的工作区/任务标识为准，切换任务不会静默跳到其他项目。

## 13. 当前需要继续统一的交互

以下内容不是缺陷结论，而是整理现状时发现的产品表达边界：

1. **“任务”和“会话”混用**：主操作使用“任务”，搜索和部分管理文案仍使用“会话”。对外说明建议统一以“任务”为主。
2. **“模版”和“模板”混用**：左侧入口当前显示“模版”，其他页面多使用“模板”。
3. **项目行的预期不够直观**：项目名称当前只控制展开/收起，切换项目依赖点击该项目下的任务或 `+`。如果继续保留，需要在视觉上强化它是分组标题。
4. **运行中提交规则与旧注释不一致**：实际行为是所有新提交都进入队列，`Cmd/Ctrl + Enter` 也不会绕过队列。后续文案、代码注释和帮助说明应以实际行为为准。
5. **扩展有两个入口形态**：左侧入口是主区域内嵌页，齿轮设置是完整设置页。两者数据一致，但返回方式和页面框架不同。
6. **设置路由多于可见导航**：部分云端和组织页面只能从上下文入口到达，需要避免用户进入后找不到再次访问的路径。
