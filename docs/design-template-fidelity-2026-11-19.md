# PPT 模板生成与 Design 编辑检查（2026-11-19）

## 定位结果

本机这次会话选择了 `ipollowork.pptx-ipollo-vi-enterprise`，原模板有 38 页。实际生成文件被改写为另一套 12 页蓝色设计，并包含不合适的文章标记。旧实现只传递文件路径、模板 ID 和 HTML 交付约定，未注册 Design Skill，也未将模板的应用清单带入上下文。格式改为 HTML 并不能保证保留模板视觉。

## 修复

- Design 包注册并携带原生 `ipollowork-design` Skill；其正文自动进入当前 Design 会话的必需上下文，避免模型漏掉单独加载步骤。模型仍使用 DSH 的原生 Agent、Skill、文件和权限服务。
- 必需上下文附带当前模板的分类、清单和 manifest 路径，明确作为来源数据处理。
- 新增 `design_edit_text`：分页读取文字位置，按版本批量替换文字，保留版式、图片、字体、脚本和幻灯片结构。旧版本、重复位置、只读及跨工作区请求会被拒绝；切换文件与写入串行处理。
- 局部修改只读取目标所在区域；完整新稿才要求检查所有页面，避免只改封面却读取整套 600 个文字位置。
- 企业 VI 模板接入颜色、字体和字号比例变量，默认视觉值保留。固定版式隐藏无效的全局背景装饰、圆角、间距和阴影控件；元素仍可单独编辑。
- PDF 导出增加后台窗口等待兜底，并跳过克隆其他页，避免后台导出停在动画帧等待。
- 元素属性先解析百分比、`cqw`、`calc()` 与主题变量，再提供给像素控件，修复调整尺寸/字号时突然缩小的问题。浮动“调整属性”直接切到“元素”，不会误停在主题页。
- 补测修复主题重置：自定义模板恢复当前文件载入时的值，关闭并重新打开属性面板后仍然有效；已应用主题则恢复该主题，不再误用正在浏览的第一套主题。

## 验证范围

从实际归档安装的隔离 DSH 客户端验证：应用同一模板、加载 Skill、模型读取和修改文字、HTML 文件卡片与链接进入 Design、文字编辑、撤销、保存和重开、38 页翻页、属性/字体/字号调整、选中元素发送 AI 编辑指令、全屏及 390px 明暗主题。

PPTX 实际下载，检查 ZIP 内容确认 38 页、编辑文字及原生文本/形状对象。PDF 实际下载。文字工具回归验证只有选中文字发生字节变化，其余模板内容保持不变。独立 Design 和 Design/Video 组合安装通过；构建、类型、源码、归档和相关自动化检查通过。

原生 Agent 链路先使用受控测试模型，再用当前开发版的实际 DeepSeek V4 Pro 验证封面替换：仍为 38 页，标题以外的 HTML 逐字节相同。该用例不能等同于所有主题、所有线上模型的完整内容质量验收。图片/语音/视频等第三方生成服务需要各自的可用配置，本次未消耗这些服务。分享网页涉及外部发布，未在测试中执行发布。

真实模型的一轮试验在完成文件写入后遇到 `IPW_SERVICE_UNAVAILABLE`，没有把它算作成功交付。收紧局部读取指引后，新会话在 4 步、26 秒内完成读取、修改和 HTML 文件卡片交付，并从卡片打开当前开发版的 Design；38 页与非目标内容的字节比较均通过。

Design 自动化检查共 136 项通过。套件共 208 项，其中 197 项通过、11 项可选跳过。根目录工具 11 项、固定上游检查和文档链接检查通过。

开发版安装后发现日常 profile 中的 13 个间接 DSH 依赖副本与固定运行时冲突，已移入可恢复的本地备份并沿用固定运行时重启，账号、凭据、会话和项目保留。未修改 DSH 源码。

交付版本：Suite `0.1.39`、Design `1.0.0-beta.37`，Design 源码提交 [276a20a](https://github.com/Devin-AXIS/deepseek-design/commit/276a20a)。归档 SHA256 为 `41a62086083ac99614ac445061b30c3e383a7c4ca72def011fdfef5405efde57`。

## 使用说明

更新插件后，从“模板”重新选择所需 PPT 模板，再说明主题和内容。通常只改内容时会保留模板版式；如需改变页数或结构，请明确提出。点击返回的 HTML 可以进入 Design 继续编辑，并从编辑器导出 PPTX/PDF。

已有被改写的 12 页文件保留，不会自动覆盖。重新套用模板会创建独立会话，方便与旧结果对照。
