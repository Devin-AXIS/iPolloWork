# Help Translate iPolloWork

We are actively looking for contributors to translate iPolloWork to your own native language.

## README translations

Translated README variants live in `docs/translations/`, and the root `README.md` owns the supported language links.

If you want to add a new README language:

1. Copy `README.md` to a new file like `docs/translations/README_<LANG>.md`.
2. Translate the content.
3. Add your language link to the supported languages list in `README.md`.
4. Open a PR.

## App UI translations (i18n)

You can also help translate the app UI via:

- `apps/app/src/i18n/`

Currently available app UI locales: English (`en`), Japanese (`ja`), Simplified Chinese (`zh`), Vietnamese (`vi`), Brazilian Portuguese (`pt-BR`), Russian (`ru`).

Locale files live in `apps/app/src/i18n/locales/`.

If you are unsure where to start, open an issue and mention the language you want to contribute.
