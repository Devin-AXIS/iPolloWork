# DSH compatibility record

English | [中文](compatibility.zh.md)

The [runtime pin](upstream.json) defines the DSH baseline. This inventory covers `dsh-v0.2.2-rc.3` (source `39163dd30f70`), Jovan at `5104d080ba`, and the November 16, 2026 working changes. Commit `4c696c2b33` separated DSH from the product source tree. Earlier migrations are covered by the [existing upgrade guides](../../docs/upgrade-guide).

## Features to verify when upgrading

Desktop `1.0.10` reconciles existing profiles through `initProfile`/`readProfileManifest` and the native `dsh.profile.bundles` selection. The private Host is required even for an already initialized profile; competing public product bundles and direct product dependencies are backed up before removal. `desktop-runtime.json.sharedPackages` identifies installation-owned Suite/Stage/Host copies, including matching versions. The last native Include overlay enables only the owned application entries; Suite enforces the distribution's account/theme/origin using the verified install-anchor package identity. Other plugin configuration and credential files remain unchanged. Recheck legacy web-only profiles, stale/same-version Suite copies, disabled entries, actual cloud login, incorrect-password classification, and a returning signed-in session in the installed Mac app. Welcome checks `/ipollowork-suite/info` before entering the workspace and distinguishes rejected credentials, sessions, outages, timeouts and throttling. See [the upgrade diagnosis](../../docs/diagnostics/2026-11-20-mac-login-and-upgrade.md).

The official-model proxy replays a gateway invocation with the same request ID only when the connection fails before response headers or the gateway reports that invocation still running. Recovery is bounded, cancellable and tied to the account generation; native pi-ai retries remain disabled. Response-stream failures and unknown upstream outcomes are not replayed. The account service separately retries explicit chat HTTP 429 rejections inside one billing invocation. Recheck native streaming, prepared calls, cancellation, account changes and exactly-once settlement on the next DSH pin. The Design editor resolves authored CSS units to layout pixels before dragging/resizing, converts pointer deltas through parent scale, and requires real movement before guide snapping; verify imported PPT percentages, stylesheet positions, content-box sizing, anchored boxes and fixed-stage zoom.

Design `1.0.0-beta.37`, bundled with Suite `0.1.39`, uses native `ctx.skills.register`, `ctx.tools.register`, required `systemPrompt.context`, workspace ownership and sandbox policy for template authoring. The packaged `ipollowork-design` Skill and revision-checked `design_edit_text` tool preserve HTML outside edited text nodes. Template checklists are bounded source data. Document activation and tool writes share the plugin lifetime queue. The original editor resolves CSS units and theme variables before exposing pixel-based property controls; floating element actions select the Element tab. The enterprise VI template retains default geometry while consuming theme tokens, and fixed native-slide layouts hide unsupported global geometry controls. PDF yielding has a timer fallback for background windows. On the next pin, verify Skill discovery/loading, required model context, stale/read-only/foreign-workspace rejection, HTML card/link opening, local media, property changes, theme persistence, 38-page editable PPTX/PDF, both themes and 390px. See the [verification report](../../docs/design-template-fidelity-2026-11-19.md). The Agent and DSH sources remain unchanged.

The [MCP connection controls](../../plugins/ipollowork-suite/src/host/mcp-connections.ts) use native `mcpManager.list/restart` and revision-checked `settings.mutate` in the web-app's `mcp-manager` namespace. They edit only one server's `enabled` field or unset a user-only entry, preserving credential references and sibling configuration. Inherited and plugin-registered entries cannot be deleted. Editing opens the native Settings document. Organization disconnect choices stay on this device in the native credential provider, scoped by verified account identity and service origin. Existing installations without saved choices keep catalog-only discovery; resolving saved choices adds one identity read per account generation, never a balance request. Verify tool withdrawal, reconnect, refresh/restart persistence, account switching, stale revisions, failed saves, deletion confirmation, both themes and narrow settings panels. Native configuration editing and plugin-owned lifetimes must remain intact; no DSH source is modified.

## Updating and verifying

Desktop `1.0.9` backs up mismatched, profile-local copies of the shipped DSH/Cordis core before official profile boot, using the existing application-owned profile lock and the signed `desktop-runtime.json` package inventory. DSH's loader preserves native profile priority, so a hoisted old core can shadow the installation even after its originating plugin is disabled. Verify an old `dsh-llm`/`dsh-typert-protocol` profile, restart/idempotence, data preservation, matching versions and external links on pin upgrades. No resolver or Agent implementation is patched. See [diagnosis and checks](../../docs/desktop-startup-and-download-fix-2026-11-20.md).

Organization MCP synchronization calls the authenticated grant catalog directly, without extra session or balance requests. Safe account-service error codes distinguish timeouts, expired sign-ins and catalog failures. Verify catalog-only requests while signed in, no network request after sign-out, and connection withdrawal when catalog synchronization fails.

The organization MCP relay preserves upstream 4xx statuses and the `mcp-method` and `mcp-name` protocol headers. The current pin's MCP SDK sends `server/discover` first; when a 2025-era server rejects the probe, the client needs the original 4xx to fall back to `initialize`, rather than a rewritten 503. Authentication, access and rate-limit failures have distinct sanitized codes; upstream error bodies are withheld. On pin upgrades, verify native discovery, legacy initialization, tool listing, expired sessions, 401/403/429 responses and upstream-body redaction.

Suite `0.1.36` and Design `1.0.0-beta.35` use the optional client service `ipolloDesignTemplates` to register organization template sources. Cordis injection/disposal controls the Organization Space template tab and clears account-scoped sources when credentials change. Metadata comes from the authorized account catalog; applying a template rechecks the exact version permission before creating a new Design document through `/document` and revision-checked `/file`. Verify Design disabled/enabled, two members with different grants, revocation, account changes and editing the resulting HTML. No organization credential is passed to Design.

With Design `1.0.0-beta.38`, the `ipolloDesignTemplates` catalog requires a SemVer-shaped manifest version. Suite's `src/host/enterprise.ts` assigns deterministic aliases to other publication labels. `src/client/organization-templates.ts` resolves each catalog entry to its exact label on authorized reads and discards the mapping on account change. Verify that a publication labeled `设计验收` appears alongside a numbered release and applies to a workspace through the native Design template picker.

Organization MCP uses the public native `mcpManager.list`, `register` and `restart` APIs. Its native settings section reads redacted status DTOs and refreshes current grants before reconnecting. Cloud runtime grants allow only the member catalog and connector transport methods; service-side membership and resource checks still authorize every call. Verify discovery, a real native Agent tool call, revocation and sign-out locally and in a cloud runtime. Organization model/tool dialogs use native Modal `contentClassName` and `footer` to keep long API routes scrollable and actions visible. Field styles target only direct raw inputs, preserving the native Add Plugin Input wrapper. Check both themes at 390px and verify publication errors distinguish missing metadata, invalid versions and conflicts.
