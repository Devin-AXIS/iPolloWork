1. On the first Video Studio launch, iPolloWork clearly says it is downloading the required video resources and shows progress. The user does not need to find or install FFmpeg manually.

2. After the verified download finishes, Video opens automatically as one native HyperFrames workspace beside iPolloWork's existing task tools. The canvas stays above the original timeline, so editing and cutting remain in the same place.

3. Clicking an element directly in the Studio canvas uses HyperFrames' native DOM property editing. Text, color, image, size, rotation, animation, and timing changes stay connected to the same composition and timeline without a separate Design or HTML page.
