1. On the first Video Studio launch, iPolloWork uses the verified codecs shipped with the desktop app. Cloud resource availability cannot block startup, and the user does not need to install FFmpeg manually.

2. After the bundled codecs pass verification, Video opens automatically as one native HyperFrames workspace beside iPolloWork's existing task tools. The canvas stays above the original timeline, so editing and cutting remain in the same place.

3. Clicking an element directly in the Studio canvas uses HyperFrames' native DOM property editing. Text, color, image, size, rotation, animation, and timing changes stay connected to the same composition and timeline without a separate Design or HTML page.
