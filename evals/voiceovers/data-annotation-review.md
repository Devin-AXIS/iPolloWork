# 数据标注：本地标注、审核和导出

用户已确认：默认标注员 → 标注并保存 → 切换审核员查看当前工作区的本地记录和详情 → 通过或退回并填写意见 → 已通过记录双方均可导出 JSON；修改后恢复待审核。角色为本机工作模式。以下分镜展开同一流程，并检查用户要求的真实素材。

1. 从主软件左侧打开数据标注，默认是标注员。实训项目包含图片、视频、真人语音和更完整的文字练习。

2. 打开文字练习，选择文字添加标签，再保存区间标注。回到列表后，记录显示待审核，重新打开仍能看到刚才保存的内容。

3. 切换为审核员，列表显示当前工作区的本地记录。打开详情检查正文和标签，填写意见后退回修改。

4. 标注员按意见修改并保存，记录重新待审核。审核员检查后通过，随后导出当前版本的 JSON 文件。

5. 切换回标注员，同样可以导出已通过记录。再次修改并保存后，记录恢复待审核，不能继续导出。

6. 图片可以拖动画布；点击音视频片段可填写并显示描述，视频还可标记关键帧、填写描述并点击跳回。保存后由审核员查看并通过，两种角色导出的 JSON 都保留这些标注。
