# right-panel-controls — Keep right-panel navigation spatially consistent

The right-side work area keeps tab actions with the tabs, moves the panel control with the panel edge, and lets users inspect output files without losing their current work.

1. 打开右侧工作面板后，新增按钮紧跟在最后一个标签后方，标签和新增入口保持在同一组里。

2. 原本位于对话区右上角的面板按钮移动到右侧面板右上角，与放大按钮并列；点击只收起面板，不关闭当前标签，再次展开后恢复原来的内容。

3. 右侧面板已经打开时，点击“产出文件”，文件列表以浮层显示，底层当前标签不会被替换。

4. 从浮层选择文件后，文件在右侧标签栏中打开，浮层自动关闭；按 Esc 也可以直接关闭浮层并继续当前工作。
