# video-layer-animation — 图层内统一动画编辑

验收叙述对应本次对话已批准的交互调整；只使用隔离作品。

1. 在动画库应用一个效果，使用中的卡片标记当前图层已应用的动画。

2. 点击使用中卡片的编辑，直接进入 Layers 对应效果，不再打开弹窗，也不改动作品。

3. 在时间轴选中属性关键帧，Layers 定位到同一属性；独立修改透明度，其他图层动画保持不变。

4. 手动编辑后的关键帧得到保留，模板参数不会悄悄覆盖；撤销后恢复原来的动画。

5. 通过工具栏下拉选择属性，直接在当前播放头打第一点，再点菱形继续打点；同一时间已有点就选中，属性行不再重复提供添加入口。右侧保留关键帧数值和继续编辑入口。

6. 在选定的旋转属性上记录两个关键帧，单独调整其中一个点的时间，原预设的透明度和其他图层的动画保持不变。

7. 下拉选择 X 立即在播放头打点，用工具栏菱形继续打第二点；修改第二点的数值后再次打点不会覆盖它。缩略图顶部显示清晰的关键帧，原有透明度动画保持不变。
