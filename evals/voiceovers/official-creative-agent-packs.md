# official-creative-agent-packs — 设计与视频插件安装、卸载和数据保留

1. 我打开 iPolloWork 的扩展设置，可以看到默认安装的两个官方 Agent Skills 插件；Design 和 Video 工作台作为软件内建能力始终可用。

2. 进入 Design Agent，可以看到它只管理两个相关 Skills；既能整包管理，也能单独启用或禁用某个 Skill，不负责安装或移除内建工作台。

3. 只关闭 Design Studio Skill 后，设计工作区仍然正常可用，画布、模板内容、选区编辑、撤销、主题调整和导出功能保持不变。

4. 卸载 Video Agent 后只会移除配套 Agent Skills；视频入口、工作区、已有项目和用户文件都保持不变。

5. 重新安装 Video Agent 后，配套 Skills 恢复，并继续打开卸载前的同一个内建视频项目；整个过程不会修改、迁移或删除任何用户数据。
