# official-creative-agent-packs — 管理创作 Skills，不改变核心工作台

1. 我打开 iPolloWork 的扩展设置，现在可以看到两个由 iPolloWork 官方提供的能力包：Design Agent 和 Video Agent；原来的设计与视频入口完全没有变化。

2. 进入 Design Agent，可以集中查看和管理设计相关 Skills，支持整包安装、更新、回滚和卸载，也可以单独启用或禁用其中一个 Skill。

3. 我打开一个已有设计模板，画布、模板内容、选区编辑、撤销、主题调整和导出功能都与升级前完全一致，不依赖 Design Agent 是否安装。

4. 进入 Video Agent，可以管理 HyperFrames 和视频工作流相关 Skills；关闭或删除这些 Skills 后，已有 Video Studio、时间线、预览和视频项目仍然可以正常打开和编辑。

5. 重新安装官方能力包后，对应 Skills 恢复可用；整个过程不会修改、迁移或删除任何设计模板、视频项目和用户文件。
