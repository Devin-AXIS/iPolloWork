# 个人本地插件集与公开线上插件

目录来源分别为本地运行目录和模拟线上接口；安装、更新、卸载与本地存储均使用真实服务。

1. 个人页展示本地插件集，包括尚未安装的插件，并且不请求线上插件目录。
2. 我从个人页安装本地插件，已安装区立即显示它。
3. 本地插件集有新版本后，我在个人页完成更新。
4. 我在个人页卸载插件，它回到可安装状态，本地插件集仍然保留。
5. 切到公开页，页面使用线上接口；我下载并安装线上插件。
6. 线上接口提供新版本后，我在公开页完成更新，自己的文件保持不变。
7. 线上更新包损坏时，安装停止，已经安装的版本保持不变。
8. 我在公开页卸载线上插件；回到个人页，即使线上服务断开，仍然可以浏览本地插件集。
