# 短片工作台完整共享 UI 迁移

隔离预览使用本地测试工程与素材，不调用付费生成。相同流程分别验证开发打包与宿主注入。

1. 顶栏、工具栏和关闭入口使用共享按钮，尺寸、图标居中、禁用状态一致。

2. 七个页面使用共享 Tabs，切换后保留项目内容，支持键盘操作。

3. 分镜、角色、剧本和轨道使用共享输入控件，自动保存正常；失败保留修改并可重试。

4. 项目、渠道、镜头、素材、画幅和帧率使用共享选择器；多选参考素材使用合适的多选组件。

5. 提醒、状态、空页面和加载过程使用共享组件，错误持续可见，成功反馈不遮挡操作。

6. 弹窗验证取消、确认、提交中、失败重试及关闭后的焦点恢复。

7. 开发打包和生产宿主注入分别验收亮暗主题、窄窗口，并核对没有遗漏的旧控件样式。
