# gsap-effect-library — Browse and use the complete GSAP effect catalog

This user-facing demo proves the leader-facing GSAP effect-library experience.

1. 用户打开 Work 素材面板，可以在“动画库”和新的“GSAP 特效库”之间切换；页面直接显示 GSAP 特效总数、官方能力覆盖率和下载状态。

2. 用户进入 GSAP 特效库，可以按照基础、文字、滚动、SVG、交互、背景、转场和 WebGL 分类浏览，并看到每个特效的动态预览。

3. 用户按插件筛选，例如 ScrollTrigger、SplitText 或 MorphSVG，页面只显示对应特效，并标注 GSAP 版本、插件依赖和来源。

4. 用户打开一个特效详情，可以预览完整效果并调整颜色、速度、时长、强度和缓动等参数，修改立即反映在预览中。

5. 用户将特效添加到 Work，特效和参数进入当前作品；已下载的特效可以离线使用，远程目录有更新时页面显示更新状态。
