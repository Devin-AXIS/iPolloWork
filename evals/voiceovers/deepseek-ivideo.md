# DeepSeek iVideo

1. 在 DeepSeek Harness 对话旁边打开 Video，就能直接进入 iVideo by iPolloWork；品牌、模板、AI 和 GitHub 都收在 HyperFrames 原生顶部栏的同一行里。

2. 点开模板入口，只看到 28 个可编辑的视频模板，不会混入 Design、PPT 或其他内容。

3. 选择 Agent Command Center 后，模板通过安全替换流程进入当前会话，原生时间线、十二秒预览和导出能力仍然完整保留。

4. 在画面里选中一个元素，元素 AI 会携带文件、稳定定位、当前文字和样式写入对话草稿，但不会替用户发送。

5. 整段 Ask AI 同样只准备当前视频项目的修改指令，并要求修改后运行会话范围内的 HyperFrames 校验。

6. 最后的导出仍然使用 HyperFrames 原生 MP4、MOV 和 WebM 流程，没有在插件里维护第二套渲染器。
