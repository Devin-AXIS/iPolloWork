# session-compaction — 原生会话压缩与统一反馈

验证用户已确认的范围：保留引擎原生压缩，修复配置保存，统一手动操作和反馈。演示使用隔离工作区、真实 DSH 运行时和本地模型接口；回复内容不代表真实模型的摘要质量。

1. 打开已有会话的上下文详情，可以看到当前用量和压缩入口。

2. 点击压缩，界面显示正在压缩。完成前，发送和重复压缩都暂时不可用。

3. 压缩完成后，界面显示完成结果并刷新上下文用量，对话中没有额外的压缩指令消息。

4. 继续发送一个问题，任务正常运行；任务进行时，压缩按钮会提示等待当前任务完成。

5. 收到回复后重新打开页面，同一会话和回复仍然保留。

6. 摘要请求失败时，界面显示失败原因，并恢复操作，不会把失败显示成压缩完成。

7. 打开不支持压缩的极简会话，可以看到明确说明。

8. 自动压缩开关只出现在支持它的引擎设置里。修改 OpenCode 开关并重新打开页面后，保存的状态仍然保留。
