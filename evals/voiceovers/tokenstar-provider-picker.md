# tokenstar-provider-picker - TokenStar is a first-class model provider

1. I open the model picker and see TokenStar listed alongside the other model providers, instead of nested under OpenCode Zen.

2. When TokenStar is not connected, I can choose its connect action and the existing TokenStar API key setup opens directly.

3. After TokenStar is connected, I expand it and can choose any model returned by the provider, including model families the app has never hard-coded.

4. I select a supported GPT model and the composer keeps the TokenStar model together with its Low, Medium, or High reasoning effort for the next message.
