# hyperframes-effect-params — 用户可以安全调整 GSAP 特效参数

1. 用户进入视频模式，打开特效目录。每张特效卡显示预览、分类，并标明是否支持参数调整。

2. 用户选择一个 GSAP 特效并打开“调整参数”。系统根据特效规范自动显示颜色、强度、速度、时长和缓动等控件，不需要用户接触代码变量。

3. 用户修改背景颜色和波浪强度，预览立即更新；所有数值都受到特效声明的范围约束，不会产生无效参数。

4. 用户修改时长或缓动方式，需要重建的 GSAP 时间轴自动重建，并保持当前预览时间位置，不会突然跳回开头。

5. 用户关闭参数面板后，已选择的特效显示配置状态；重新打开时，刚才的实例参数仍然保留。

6. 用户发送视频请求，iPolloWork 把特效 ID、版本和结构化参数一起交给视频 Agent。生成项目后，时间轴支持稳定定位和逐帧渲染，同一时间点重复渲染结果一致。
