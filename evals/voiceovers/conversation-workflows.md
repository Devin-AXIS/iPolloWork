# conversation-workflows — 直接开始，展示实际协作

1. 新建对话时直接输入需求，保留引擎选择，不再要求选择工作模板或配置预设角色。

2. 发送一条简单消息，获得引擎的真实回复；当前概览顶部只显示一行对话标题，不重复整段发送内容；保留任务和用量布局，只展示主智能体。

3. 打开已有 OpenCode 视频对话，实际参与的子智能体统一显示头像、状态和原生子对话入口；运行数据分别统计主智能体和每个子智能体，临时分工也单独列出。

4. 点击一个实际子智能体，能看到它保存的真实工作记录；返回主对话后，任务仍然归属这次对话，每张执行任务卡都有醒目的头像，与概览里的同一个智能体一致。

5. 打开已有 Codex 对话，同样展示真实子智能体；无论它使用过预设还是临时创建，都保留在同一个列表中；没有返回用量的智能体显示未计量，不会当成零。

6. 将窗口收窄到五百二十像素，概览、真实智能体和任务卡上的执行者头像保持可读、可点，没有横向溢出；预设能力保留在底层，默认界面不加载它的编辑入口。
