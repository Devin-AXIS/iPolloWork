# 对话过程、流式回复与成果的交互验收

1. 思考时，对话区只显示一个紧凑状态，长段推理默认收起，不会把页面撑长。

2. 点击过程入口，可以查看完整记录；展开和收起有短促过渡，新的输出保留我的选择。

3. 唯一活动状态入口显示当前工具并柔和脉动，工具条目只作静态摘要；完成后短暂确认，再平滑收进历史详情。需要我确认时保留条目，活动动画立即停止。

4. 工具任务尚未明确给出最终回答时，文字保留为可展开的回复草稿，过程说明和代码不进入正文。

5. 最终回答开始后，文字在原位持续增长，已经读过的内容保持稳定。

6. 回答写完后，导出或保存仍显示正在收尾；全部完成后，成果卡片轻淡入并可以打开。

7. 停止任务后，保留已产生的内容和明确的停止状态；开启减少动态效果后，状态、工具和展开过渡都停止动画。

8. 向上翻阅或选择文字时，后续输出不抢滚动位置；点击新内容入口可以回到最新位置。
