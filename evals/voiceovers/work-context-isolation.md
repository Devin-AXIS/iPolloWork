# Personal and enterprise work contexts

1. 在个人空间中，左侧只显示个人项目和聊天记录；当前会话、扩展、模板与记忆均属于个人。

2. 切换到已经加入的企业时，先显示 iPolloWork Logo 过渡动画，再进入这个企业自己的工作区；左侧项目和聊天整体替换，不出现任何个人记录。

3. 企业空间中的扩展安装、授权和模板独立保存；记忆页面不读取个人云端记忆，资源来源可在个人与当前企业之间明确选择。

4. 切回个人后，原来的个人项目、聊天与已安装扩展完整恢复；账号页只有“个人 / 已加入企业”这一套切换入口，不出现旧团队、创建团队或第二套空间入口。
