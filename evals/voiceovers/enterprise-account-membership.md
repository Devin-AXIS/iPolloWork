# Personal and enterprise membership

The user is already signed in to iPollo Cloud and has completed the join-code flow once. This proof covers the single Personal/Enterprise work-context system.

1. 打开账号页，个人空间和已经加入的企业会显示在同一列表中；刚加入的企业自动成为当前企业空间。

2. 点击个人空间后，项目、聊天列表与当前会话整体切回个人；企业项目和聊天不会出现在个人空间。

3. 再选择已经加入的企业，聊天列表恢复为这个企业自己的历史与上次会话，个人聊天不会混入，同时模板与扩展来源也随空间切换。

4. 点击退出企业会先显示明确确认，说明退出将移除 Enterprise Server 上的真实成员关系；所有者则必须先转移所有权。
