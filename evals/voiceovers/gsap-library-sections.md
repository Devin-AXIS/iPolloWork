# gsap-library-sections — 四类可附加 GSAP 动画

1. 动画库现在只保留四个清晰入口：开场、结尾、转场和字幕动画，每一类先提供四个可复用预设，总计十六个。旧的混合分类不再出现在当前动画库中，后续 AI 批量生成也会遵守同一套分类和数据契约。

2. 用户可以直接在视频画布里选中文字、字幕、图片、图形或组合。当前示例选中标题文字后，动画库会显示兼容状态，并立即启用所有可用于文字的“应用”按钮；切换到动画库不会丢失画布选中状态。

3. 选择 Caption Phrase Lift 后，预设会附加到当前文字，而不是生成一段不可编辑的视频。系统自动回到属性面板，原有动画和新动画都保留为 GSAP 动画卡片，开始时间、时长、关键帧和缓动仍可继续编辑。

4. 最后把新动画的时长从零点七二秒改为一点二秒。属性面板立即显示新值，选中的标题保持不变，同时改动写回 GSAP 源码和动画引用标记，证明动画库、画布选择和可视化属性编辑已经形成完整闭环。
