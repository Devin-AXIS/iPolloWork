# gsap-library-sections — 动画与场景的独立分区

1. 用户打开设计工作台后，顶部只有“设计、动画、场景、导出”四个入口；进入动画页，固定搜索框下方分别显示“文字动画”和“界面动画”。

2. 文字动画和界面动画各自拥有固定标题、默认三列卡片和独立的纵向滚动条。普通滚轮只滚动所在区域，按住 Ctrl 滚动则会同步把卡片密度调整为每行一到四张，并记住用户的选择。

3. 用户搜索动画时，结果仍保留在原来的两个分区中；没有匹配结果的分区显示空状态，并且两个分区的滚动位置都会回到顶部。

4. 卡片初始只显示静态缩略图。快速划过不会创建预览；稳定悬停约一百五十毫秒后才加载预览，始终最多只有一个预览运行，并锁定为正常的一倍速播放。

5. 切换到场景页会立即清理动画页预览，并显示相同结构的“转场场景”和“背景场景”两个独立区域；点击卡片仍沿用原来的添加流程。
