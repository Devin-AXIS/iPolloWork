# video-nested-groups — 场景嵌套组与属性编辑

对应本次对话已确认的嵌套组交互，只在隔离样例中执行修改。

1. 总览保留共享图层，每个场景各占一条轨道，音频合并为一条轨道。

2. 双击场景后直接平铺内部元素，隐藏纯布局容器；有整体动画的组保留属性行，子元素注明所属组，点击名字展开属性，不再继续进组。只预览当前场景和它的时长，左上角可返回总览。

3. 单击图层名字展开已有属性和关键帧，连接线表明属性属于哪个图层，片段不再重复显示名称。

4. 场景本身的动画可以在各自轨道展开，进入场景后播放范围限制在当前场景。

5. 去掉左侧展开箭头和加号，默认只显示已有动画属性；原有作品动画和手动关键帧保留。
