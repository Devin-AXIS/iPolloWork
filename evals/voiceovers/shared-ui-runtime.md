# 共享 UI：同源组件，两种加载方式

1. 开发插件打包共享组件库，生产插件从宿主注入同源运行时。两种模式都能打开短视频项目创建弹窗，使用32px共享按钮和输入框，不依赖外网。

2. 在隔离预览中注入一次保存失败。提交中不能重复执行，失败后弹窗与草稿保留，错误关联输入，重试调用真实本地服务并保存项目。

3. 切换亮暗主题，再缩小到390px。共享控件和插件界面跟随主题，弹窗保持窗口边界；无关上下文更新不重置主题，取消或Escape后焦点返回入口。

4. 在宿主提供的运行时中渲染真实React共享组件，并与HTML适配控件比较尺寸和样式；不兼容版本明确拒绝，不静默降级。组件级证明不等于已安装插件或完整Electron发布验收。
