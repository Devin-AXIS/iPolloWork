# 共享 UI：真实客户端安装验证

只连接专用 Electron 验证窗口。插件通过内置目录安装，任务通过客户端 Control API 创建；账号、工程和数据库使用临时目录。保存故障为一次明确注入的传输失败，重试走真实嵌入式服务。

1. 已安装的短片工作台在真实 Electron 中打开，宿主注入共享运行时。新建项目弹窗使用共享的按钮和输入框，控件高度为32像素。

2. 注入一次保存失败后，弹窗保留填写内容，并把错误关联到输入框。提交中禁用重复操作，恢复后可以重试。

3. 再次提交调用真实本地服务，项目文件写入临时工作区，成功后关闭弹窗，焦点回到新建入口。

4. 刷新客户端后，已安装插件重新打开，共享运行时再次加载，刚保存的项目仍然存在。这证明同版本重新加载和数据保留，不代表客户端跨版本升级已经验收。

5. 在验证窗口改变宿主主题，并把插件容器设为390像素。真实宿主桥接把深色主题传入插件，新建弹窗不越界；按Escape关闭后，焦点回到入口。这里测试主题状态和容器尺寸，不测试设置偏好的持久化。

6. 在同一个生产插件中注入不兼容的2.x运行时，插件显示更新客户端的提示，不启动项目业务。随后恢复原页面；这证明拒绝路径，不代表已发布2.x版本。

7. 恢复正常运行时后添加图片节点，用键盘选择风格。共享 Select 保持32像素，真实项目文件保存风格和提示词，提交后焦点回到选择器；不调用生成渠道。

8. 注入主次版本满足要求、但缺少所需函数的测试运行时。插件显示缺少组件的更新提示并停止初始化，再恢复正常页面。这是能力拒绝路径，不是正式客户端升级发布测试。
