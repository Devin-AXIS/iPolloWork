# 共享核心组件调用

经用户确认，核心控件优先全部可调用，不以八类为范围上限。演示使用隔离回调，不触发文件或模型业务操作。

1. 插件从共享运行时取得基础组件。编辑字段、触发失败并重试；草稿保留，多选和搜索选择可操作。

2. 打开菜单并执行命令。共享菜单和命令组件反馈实际调用结果，浮层可以关闭。

3. 打开确认弹窗，取消不执行；确认执行一次。抽屉关闭后焦点返回入口。

4. 查看表格、卡片、状态、进度和布局组件。切换详情，展开说明，显示成功提示；暗色窄容器仍可操作。

5. 关闭按钮使用同一份共享实现。在亮暗主题、不同字号、窄窗口和缩放下，图标保持居中；鼠标点击和键盘都能关闭提示。

6. 信息、成功、警告和错误提醒使用对应的语义浅背景，没有边框。切换亮暗主题后仍可区分；关闭和重试可操作，开发打包与宿主注入显示一致。

7. 插件直接使用公共图标，S、M、L保持14、16、20像素。前置、后置和纯图标按钮共用Button，28、32、36像素下仍对齐；点击、键盘、禁用和加载反馈在亮暗窄窗口及两种接入方式中一致。
