# unified-engine-plugin-runtime — Plugins work consistently across AI engines

1. In a DeepSeek Harness project, I can install the same plugin package and see that it is ready to use.

2. DeepSeek Harness can use plugin MCP tools, service actions, and right-side Workspace Apps without extra setup paths.

3. I can switch to an OpenCode project and the same plugin capabilities continue to work without any regression.

4. When I uninstall the plugin once, its Skill, MCP, command, Agent, and Workspace App entry disappear cleanly from both engines.
