# native-agent-results — 原生预设与临时子智能体

本流程验证原生角色、真实 Skill、主对话结果卡片和临时子智能体入口。完整视频制作与播放验收由视频交付流程验证。

1. 在 OpenCode 视频对话里先只做分镜，实际调用原生分镜 Agent，保存结果后停止制作流程。

2. Codex 视频对话也完成相同的原生分工，主对话展示保存的分镜，用户仍决定下一步。

3. 在 OpenCode 对话内修改预设指令，后续原生子 Agent 使用修改后的内容；独立的临时分工一起协作，主对话收回两者结果。

4. Codex 也执行相同的对话内预设与临时分工协作，角色配置跟随本次引擎，实际执行可在同一个概览查看。

5. 引擎自行创建的临时子 Agent 也显示在原有子智能体列表中，自动生成与其他 Agent 一致的彩色头像，再次打开时保持一致。打开它可查看实际过程和结果，预设分工保持不变。
