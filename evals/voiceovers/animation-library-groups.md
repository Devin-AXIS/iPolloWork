# animation-library-groups — 动画模板按使用状态组织并支持就地编辑

1. 视频时间线工具栏严格使用 Figma 设计中的 SVG 图标和分割线尺寸；未选择元素时，只保留可用的操作提示，暂不展示“录制手势”入口。

2. AI 正在修改视频时，画布正下方会显示深青色状态提示卡片，浅青色加载图标持续旋转，并提醒用户暂时不要手动修改；卡片外层透明，不会形成横贯画布的色带。

3. 用户还没有选中元素时，Animation 仍然展示完整动画库，可以搜索和浏览；此时点击应用不会修改视频，只会提示用户先选择一个元素。

4. 用户选中视频画面中的一个元素后，搜索框下方出现当前元素信息和动画分类；还没有已使用动画时，直接展示可用动画，不显示空的“已使用”和“未使用”分组。

5. 用户点击一个未使用的动画，卡片先显示应用中的加载状态；保存完成后，卡片进入“已使用”区域，并出现已应用标签、编辑和取消应用按钮，相关提示统一使用白底和黑色文字。

6. 用户点击编辑，卡片附近弹出更宽的动画设置浮层；开始和结束时间可以直接输入数字，不显示上下微调按钮，浮层内只保留完成操作，取消应用仍由卡片负责。

7. 用户点击取消应用，对应动画会从元素上移除并回到直接展示的可用动画列表；切换中英文后，分类、状态、按钮和编辑浮层中的所有文字都会同步切换。
