# external-agent-delegation - Modes stay simple while external agents remain pluggable

1. The model control now sits beside a matching work-mode selector with clear Execute and Plan options and simple icons.

2. From the plus menu I choose Delegate external agent and see DeepSeek Harness discovered from the installed plugin, without adding it to the main mode switch.

3. Choosing DeepSeek Harness closes the menu and prepares its delegation instruction in the composer, ready for me to add the actual task while Execute remains selected.
