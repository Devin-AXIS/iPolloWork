# wechat-official-plugin — Install and configure the WeChat Official Account plugin

1. I open the plugin catalog and find WeChat Official Account beside the existing official integrations, with a clear description of content publishing, comments, messages, fans, menus, and automation.

2. I install it and open its dedicated detail page, where the plugin shows one protected WeChat service and seven independently controllable operating skills instead of a loose collection of files.

3. I turn off Comment Operations only, demonstrating that an operator can narrow the agent's access without removing article publishing or the rest of the account workflow.

4. I open the connection form and see that the account uses its AppID and AppSecret through iPolloWork Authorization Center. The form explains the verified service-account requirement and never exposes credentials after saving.
