# Image Studio session outputs

User-approved behavior: generation and edit results belong to the initiating session, edits preserve originals, reopening retains the outputs, and no chat messages are inserted.

1. 在图片工作台生成图片后，打开当前会话的产出文件，可以直接找到这张图片。

2. 编辑结果会另存为新图；即使处理中切换会话，两张图片也只保留在发起操作的会话中。

3. 重新打开当前会话，原图和编辑图仍在产出列表中，点击卡片可以继续查看和编辑。
