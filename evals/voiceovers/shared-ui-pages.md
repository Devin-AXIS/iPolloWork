# 共享组件本地整合：客户端逐页验收

使用专用 Electron 测试数据；授权只触发本地必填校验，插件导入使用不合法地址由本地服务拒绝，不登录、不保存真实凭据、不调用生成渠道。短片插件完整操作另由 shared-ui-client 验证。

1. 在真实设置页切换深浅主题，当前选择与页面颜色一起改变。语言选择和设置内容仍能正常显示。

2. 在授权配置中填写一部分测试内容，必填校验就地显示浅背景错误，已经填写的内容保留。按 Escape 关闭后，焦点返回配置入口，没有保存凭据。

3. 已安装的短片插件可以在插件管理中找到。导入一个不合法地址后，页面保留地址并显示无边框错误，关闭后返回添加入口，不安装其他插件。

4. 未登录时，云市场明确提示登录，不把空列表当作加载成功。进入账号页仍然可以看到登录入口，不进行实际登录。

5. 回到工作区打开权限浮层，选择内容可读；按 Escape 关闭后焦点返回入口。在缩窄的客户端视口中重复检查，不让浮层横向越界。

6. 模板中的普通操作按钮保持32px，筛选使用共享按钮和浮层。切换选中状态只改变颜色，不改变文字大小或按钮尺寸；关闭按钮使用28px点击区和16px居中图标。

7. 插件页的标签和授权配置按钮内容居中，设置按钮保持28px。插件导入与其他弹窗使用同一种关闭按钮，键盘焦点提示仍然可见。

8. 工作区模型按钮只显示名称和下拉箭头，不显示前置图标。缩窄窗口后名称仍然可读，打开和关闭菜单仍可操作。
