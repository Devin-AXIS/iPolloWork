# 共享 Select、Dialog、Toast

隔离预览使用真实插件和本地项目服务；传输失败与旧运行时是明确注入的测试条件，不调用生成渠道。

1. 打开新建短片弹窗，填写名称并提交。共享 Dialog 和 Input 保持32像素控件；提交中禁止重复操作和关闭。

2. 注入一次保存失败，错误留在输入框旁，草稿不丢失。重试成功后项目真正保存，弹窗关闭，焦点返回入口，Toast 提示短片已创建。

3. 添加图片节点，在风格提示中使用键盘打开 Select。Escape 返回选择器且不改变值；选择失败时恢复原值，错误就地显示。

4. 再次选择风格并保存。选择器显示新值，真实项目文件记录所选风格和提示词，焦点仍可继续操作。

5. 切换深色主题并缩小到390像素。Select 浮层和 Dialog 保持容器边界，Toast 跟随主题；不改变作品本身的配色。

6. 取消弹窗后焦点返回入口；Toast 可以用键盘关闭，不遮挡后续操作。

7. 注入旧版1.x运行时，但不提供新组件。插件明确提示更新客户端，不启动业务，不静默复制另一份组件库。
