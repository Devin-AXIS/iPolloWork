# Video motion quality runtime proof

Internal demo: prove executed motion timing and a playable comparison export. Ordinary generation quality remains a separate observation; the user authorized autonomous implementation. This narration records the demo criteria stated before implementation and scopes the result to technical runtime and the concrete sample.

1. 声明的动作必须在真实时间线上执行，提前结束的入场动画会收到错误，而正确的嵌套、错开和停顿仍然可以通过。

2. 实际样片保留同一张想法卡片和它的任务节点，动作有推进、有收束，正向和反向寻址都能得到相同画面。

3. 样片已经导出成可播放的视频。可以用正常速度回看任务推进到结果的变化，并打开源文件继续编辑。
