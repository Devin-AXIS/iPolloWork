# chat-message-alignment — 对话内容共享清晰的对齐基准

1. 在一次完成的对话中，“已处理”摘要、AI 正文、文件卡片和回复操作按钮沿同一条左边线排列，用户消息仍然靠右且气泡文字左对齐。

2. 生成结果只在正文中保留说明，完整路径收进文件卡片的更多操作；卡片使用清晰的作品标题和“类型、时长、场景数”摘要，点击整张卡片即可打开。

3. 鼠标移到文件卡片上时，下载和更多操作才会出现；用户向上阅读时，“回到最新”停在内容列外侧，点击后再回到对话末尾。

4. 中文对话在 macOS 上使用更清晰的十五像素正文、标准中等字重和二十四像素行高，重点内容适度加粗，整体阅读密度更接近系统原生应用；Windows 的显示保持不变。
