# 字段输入组件

`src/ui/fields/input.tsx` 是所有编辑面的唯一输入入口，接受 `field / value / onChange`。它根据现有字段注册器的 `input` 类型选择控件；控件不写数据库、不调用 AI，也不持有业务保存逻辑。表格单元格、记录详情、文档引用表和自动化表单复用这个入口，筛选复用相同的日期和选择控件。

- 日期、日期时间、时间、日期区间：共用按需加载的 `TemporalInput`，支持日历选择、键盘导航、直接输入和清空。日历日期按本地日期处理；时间点保留时区和秒/毫秒精度。
- 单选、多选、关联：选择器、搜索、已选状态及清空。关联数据加载单独留在适配入口，不放入通用选择控件。
- 标签：标签块、删除、Enter 添加；未按 Enter 的文字仍包含在草稿中，直接保存不会丢失。
- 数值、金额、进度、评分：精确数字输入、金额分组预览、滑条配数值、0–5 星选择与独立清空。金额全程保存十进制字符串，不通过浮点数转换；0 与未填写保持区别。
- 图片、文件、链接：HTTP(S) 地址输入、图片预览和打开入口。沿用已有引用字段，不增加上传服务。
- 邮箱、电话、勾选、长文本、JSON：对应输入语义、开关、多行及等宽文本输入。

数据校验与保存继续使用已有字段定义及 API。新增普通扩展字段只需声明现有的 `input` 类型即可复用输入层；未加载扩展保持只读。没有新增数据库表、迁移或运行依赖。

输入外观统一使用 `theme.css` 的输入底色、边框和焦点变量，内置字段及插件通过共享组件继承。单选、联动和省市搜索使用相同的选项高亮及弹层样式；日期弹层固定为紧凑宽度，覆盖组件库默认的触发器最小宽度，并受视口约束。月份选择复用现有 Select。进度滑条按整数步进，避免原生 `step="any"` 产生超出数据库四位小数上限的值；数值框仍可手动输入小数。金额预览只在千分位格式与输入不同的时候显示。

独立插件也可注册 `fieldEditors`，由同一入口加载自定义输入和配置。自定义单元格统一提示 Ctrl / ⌘ + Enter 保存；浮层在窄屏或列移出视口时仍限制在屏幕内。文档嵌入表格的按钮及其文字、图标保留自身交互，不让文档编辑器抢走焦点。

验证：类型检查和生产构建通过；输入值、中英文、预设、字段管理和详情共 19 项测试通过。浏览器完成桌面及 375px 输入操作、浅深色和英文日历检查；对实际保存结果核对 15 项值/精度/关联断言。日期、标签在单元格编辑保存，其余类型在共享的详情编辑器验证。随后补充了独立联动字段的表格快捷保存、文档内鼠标打开、嵌入表格省市编辑、列宽调整及同一记录回读验证；文档原文和表引用保持。输入/中英文 5 项、文档引用 2 项针对性检查通过。测试使用隔离数据库。构建仍提示主界面及现有文档编辑器分块超过 500 kB。
