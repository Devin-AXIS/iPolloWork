# iPolloWork Video Compose

When the active task contract requests live production, publish the first complete short scene as the motion audition before expanding the film. Keep the composition's data-duration equal to the ready prefix and use the supplied data-ipw-live-id/status markers. Append complete scenes with their required media atomically; preserve the published prefix and apply mid-generation direction only to unpublished scenes. Defer full-film checks until the final publication. This live path takes precedence over whole-film asset, storyboard and narration batching.

When the task permits `media/video_live_opening`, provide the actual title/supporting copy to that host action before reading catalogs or authoring HTML. It reuses the local scaffold motion; do not install another opening or rewrite the published scene. Existing templates, first-scene audio/media requirements, no-intro requests and recipes-only work use normal first-scene assembly.

Read [shared boundaries](../ipollowork-video-studio/references/video.md) when unknown, the saved storyboard and current entry. Initial generation or substantial motion redesign must read [motion principles](../ipollowork-video-studio/references/video-motion-principles.md) and the selected recipe's actual implementation before authoring. Load only relevant [Compose](../ipollowork-video-studio/references/video-compose.md) sections; small edits read affected rules and preserve unrelated choreography.

Build visible cause, change and consequence with fitting installed recipes or justified editable custom work. For initial generation or substantial motion redesign, complete [a continuous motion audition](../ipollowork-video-studio/references/video-compose.md#motion-audition) before expanding the film. Preserve tokens/variables/hooks/media and the authoritative timeline. Existing audio does not request synthesis; hand off only new required speech/sound and reconcile measured timing. Save and check the real source using the existing media tools; the native main Agent integrates, repairs and delivers the result.
