# 普通用户抖音运营（模拟 AI 与平台结果）

1. 添加抖音账号后，直接打开独立的扫码登录入口，普通用户无需填写应用密钥。

2. 点击识别账号会请求当前 AI 会话核对网页登录身份。这里用模拟身份回写，验证无 API 权限的账号也能使用搜索入口。

3. 搜索请求交给 AI 操作浏览器，模拟网页结果保存后回到运营台。每条结果都能填写评论并发送。

4. 评论任务保存所选视频和原文。这里模拟提交结果不确定，记录显示待核对并阻止重复发送，没有向真实抖音提交评论。

5. 已有网页登录账号直接复用，发布前先保存任务。搜索中断占用账号时，从记录结束读取，旧凭证失效，原发布任务保留。这里继续模拟发布遇到短信验证，草稿和记录均显示待核对，没有向真实抖音发布。

6. 用户验证后核对原任务，填写实际作品链接即可保存回执。任务不会重复创建，记录页可以查看作品；此处仍为隔离测试数据。
