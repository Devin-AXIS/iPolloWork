# douyin-ops — 抖音运营台本地工作流程

本演示驱动真实工作台和持久化服务，抖音网络返回使用明确的测试账号与模拟接口；不代表生产账号已授权或内容已发布。

1. 打开抖音运营台，可以看到账号、创作、作品、评论、搜索和操作记录，未配置时清楚显示接入步骤。

2. 保存应用配置后，通过测试授权回调连接账号。工作台显示账号身份和实际授权权限，不显示应用密钥。

3. 导入视频、填写文案并保存草稿，切换账号前的修改会保存，返回原账号仍能继续编辑。

4. 点击发布后，工作台保存模拟接口返回的提交回执，同一草稿不会重复发送。

5. 回复发生超时后，操作记录显示结果待核实，需要先到抖音核对实际情况。
