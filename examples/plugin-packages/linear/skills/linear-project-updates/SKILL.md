# Linear Project Updates

1. Resolve the exact project and reporting window.
2. Read current milestones and a bounded set of relevant issues.
3. Summarize shipped outcomes, active work, blockers, risks, and next actions with links when available.
4. Keep planned, in-progress, merged, and deployed work distinct.
5. Preview the update before publishing it to Linear and verify the saved result.

Avoid activity lists without outcomes. Do not manufacture dates, progress percentages, or confidence levels.
