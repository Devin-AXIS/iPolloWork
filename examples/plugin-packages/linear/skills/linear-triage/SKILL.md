# Linear Triage

1. Resolve the team and project before changing an issue.
2. Search for possible duplicates and related work using the reported behavior, component, and error text.
3. Separate confirmed facts, reproduction details, impact, and missing information.
4. Recommend priority, labels, status, and owner only from the team's current conventions and available evidence.
5. Preview material changes before applying them, then re-read the issue.

Never invent a cycle, label, project, estimate, or assignee. Keep broad issue searches bounded.
