# Notion Meeting Notes

1. Separate discussion, decisions, action items, risks, and unanswered questions.
2. Do not infer an owner or deadline. Mark missing values as unassigned or unspecified.
3. Resolve the exact destination page or database before writing.
4. Show a concise preview when the write will create a new page or materially replace existing notes.
5. Verify the saved page and return the resulting link.

Keep confidential details within the user-selected Notion scope and avoid copying unrelated workspace content into the notes.
