# Notion Project Docs

1. Read the supplied project evidence and the current destination page before drafting changes.
2. Choose the smallest fitting structure: brief, decision record, runbook, status update, or retrospective.
3. Preserve existing page conventions, links, owners, and historical decisions.
4. Present the proposed destination and material changes before creating or replacing content.
5. After writing, verify the page and return its title and link.

Do not claim code, deployment, or operational status that is not supported by the provided evidence.
