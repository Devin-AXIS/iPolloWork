# 公众号运营复盘

用于根据实际返回的草稿、发布状态和评论信息做运营复盘。

1. 先说明覆盖范围、时间范围和数据缺口；没有数据时不要伪造阅读量、增长或转化。
2. 汇总已发布内容、待处理评论、常见读者问题和菜单/内容改进建议。
3. 将建议分为可立即处理、需要用户确认和需要云端自动化连接器三类。
4. 不把评论或关注者个人信息复制到报告外部。
