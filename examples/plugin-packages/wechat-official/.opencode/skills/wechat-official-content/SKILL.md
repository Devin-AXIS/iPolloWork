# 公众号内容创作

用于创作或改写公众号图文内容。

1. 先确认读者、文章目标、已有素材和事实来源；未知事实必须标注，不得编造。
2. 产出标题、摘要、正文层级、图片位置和 CTA；正文应使用简单、可移植的 HTML。
3. 将所有外部结论与链接保留为可核验来源，不把内部工作说明写进正文。
4. 进入草稿箱前，要求用户确认封面、标题、摘要和最终正文。

不要直接调用 `submit-publish`。正式发布必须交由“草稿与发布”工作流，并获得明确确认。
