# 小红书发帖与评论工作台

验证真实运营台界面、JSON-RPC 按钮、插件服务、素材文件和持久化状态。AI 内容、图片/视频供应商与外部提交使用明确的本地测试替身；不向真实小红书发送内容，不消耗生成额度。桌面右侧暂时展示隔离的演练页面，结束后恢复。

1. 互动拆成发帖和评论。填写创作要求，让模拟 AI 返回标题和正文；保存为账号专属草稿，刷新后内容仍在。

2. 图片工作台的模拟生成结果经过真实素材导入接口回填草稿，页面显示图片和帖子预览。发布按钮将草稿锁定，模拟提交完成后回写完成状态；重复点击不重复提交。

3. 新建视频草稿，视频工作台的模拟结果经过同一个素材接口导入，预览能播放真实 MP4 文件，并保留独立的视频帖子类型。

4. 输入关键词并搜索，返回演练帖子。按点赞数排序，选择帖子并润色评论；评论可逐条编辑和保存。

5. 发送所选评论后显示完成状态；自动找帖评论按限定数量执行，跳过同一账号已经处理过的帖子。账号切换只切换本模块的数据，不会跳回账号页。
