# 日程连接小红书：本地模拟演练

验证已有日程调度器与插件操作的连接。调度回调使用固定测试内容代替模型生成，操作真实桌面的独立浏览器，所有发布和互动只到本地模拟网页。没有创建用户的生产日程或向真实小红书发送内容。

1. 到期任务使用指定的产品账号发布一篇图文，模拟页面显示文章和四张图片。再次处理同一次任务时，保留原来的发布结果。

2. 下一次任务使用编辑账号，在另一个账号的文章下面发表评论。浏览器账号与任务指定账号一致，评论回写到这个账号的互动记录。

3. 编辑账号还可以回复他人帖子中的指定评论。页面把回复显示在原评论下面，运营台保留评论和回复各自的结果。

4. 文章出现在发布账号的数据面板，评论和回复出现在执行账号的互动面板。已有账号绑定保持不变，日程保存本次执行会话。
